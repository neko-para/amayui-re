# 复现：从 OPTION / GAMESTART 退回 TITLE 时，按钮先于其余内容渲染出来

对应缺陷：`REQ-01M66CV5W8FWNY7B165CXSM8HB`（open）。

## 观测点（窗口模式）

从 TITLE 进 **OPTION**，再退回 TITLE；以及从 TITLE 进 **Game Start**，再退回 TITLE。

- 观测：TITLE 的按钮（Option / Game Start / …）**提前一整块出现**，不跟界面其余内容一起渐变；
  看起来像"它们没参与这一次淡入，而是上一帧的残留"。
- 期望：退回 TITLE 时整屏一起渐变（与真机一致）。

## 为什么像"渲染时序"而不是"渐变参数"

同一屏里**只有按钮**提前出现 ⇒ 更可能是"按钮的绘制条目被重建 / 复用了上一轮的纹理或条目，
而背景走的是另一条淡入路径"，或"重建发生在淡入的起点之前/之后"。

## 下一步（取证方向）

1. 抓 `TITLE` 退回那一刻的绘制条目表：按钮条目的键 / 纹理 id / 颜色窗起点，与背景条目对比；
2. 看 `0x71`（清层）与 `0x202`（颜色窗）在这一屏的**先后**；
3. 判据方向：同一屏的所有条目，颜色窗起点必须在同一拍盖章（或按脚本明确分档）。
