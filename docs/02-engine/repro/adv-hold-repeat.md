# 复现：ADV 里**长按**鼠标会持续推进（引擎几乎只有单次操作）

对应缺陷：`REQ-01M66CV922WE91Y7HPCJTC25WV`（open）。

## 观测点（窗口模式）

ADV 对话里**按住**左键不放：

- 当前实现：一句接一句地持续推进（像"连发"）。
- 真机：几乎不推进 —— 引擎的长按 repeat 逻辑极少，推进是**单次操作**（按一下进一步）。

## 机制 suspicions（待核）

`0x72` 的"等推进"放行现在是**电平触发**：只要左键仍按着，脚本重新武装 `0x72` 后**当拍就被放行**，
于是按住 = 连续推进。若引擎是"按一次放一次"（边沿 / 一次消费），这里就错了。

## 判据方向

按住 2 秒（脚本时间线：一次 down、2 秒后 up）：

- 引擎行为：只推进 **1** 次（或 0 次，取决于按下是否要求"本拍新按下"）；
- 当前实现：推进 N 次。
  ⇒ 用一个"按住 2000 ms 只允许推进 1 次"的判据把它钉住。
