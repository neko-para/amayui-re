1. **第一句的门（静态导出，⛔ 未经运行验证）**：`await position SC0000 0x6AB4 0x6B90`

     `show-text 0 "「凄いな、年代物の遺跡だ。修理の依頼を受けて正解だった」"`（第 1694 行）+ `wait-for-input 0`（第 1695 行）+ `end-text-line` + 分支收尾。
   - **自校验**：第 1694 行的 sha256 前 8 = `b2d6afd9`，与 `data/translations/patch.json` 的
     `{"op":"replace-line","i":1326,"sha8":"b2d6afd9",…}` 一致。
   - 清单里的 `label_%08x` **就是绝对字节偏移**（`header.length + (instr.offset<<2)`，见 `packages/age-format` 的 `disassemble.mts`），
     与 `emu-ctl sample` 的 `pos` **同一坐标系** ⇒ 不需要换算。
   - 验证方法：补完渲染 shim 后跑下面的配方，`--control-root` + `emu-ctl sample` 看 `script=="SC0000.BIN"` 且 `pos ∈ [0x6AB4,0x6B90)`；
     然后再点一次中央，看它是否推进到下一页（这才是"停在第一句且能吃输入"的证据）。
2. **⛔ 不能用"稳定"当判据**：这一页有**文本尾光标**在闪 ⇒ `pos` 与像素都不会"连续 N 帧不变"（用户 2026-11-17 口径）。
