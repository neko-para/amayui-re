## 改配方时的硬约束（给将来动手的人，⛔ 不是本轮要改的内容）

- `scripts/recipes/README.md:14–28`：5 条 `click` 指令行是需求树的 `repro:` 锚（`click 1070 480` / `650 320` /
  `1186 373` / `1180 640` / `830 592`）⇒ **一个空格都不许改**；`650 320` 在 `sn0000-save.plan` 与
