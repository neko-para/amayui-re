# apps/inspector — 真机探针（.NET 10 / C#，**重写计划**）

## 1. 职责

挂在**真实游戏进程**上做只读观测：定位解释器实例、按偏移读全局 / 帧 / 局部 / 内部对象字段、
固定间隔采样、导出快照 —— 为"engine 内部 object model"的逆向提供 runtime evidence。

## 2. 本轮状态：占位

本目录**只有这份重写计划**，没有代码。

## 3. 决定：按新结构重写（不搬旧代码）

用户口径（本轮确认）：旧仓 `app/amayui-inspector`（.NET 10 / C# / WPF / CLI / Core）**不迁移**，
只作**重写参考**（登记为 `corpus/assets.json` 的 `app/inspector-old`，`role: rebuild`）。

## 4. 工具链口径

* **独立工具链**（.NET 10），**不进 npm workspaces**（与 `packages/host-input` 的 CMake 同理）；
* **语言口径不适用于它**（`AGENTS.md` §3 那条只管 JS/TS 落点；本 app 是 .NET，走自己的工具链）。

## 5. 重写时必须钉住的纪律

1. **只读**：只允许 `OpenProcess(0x0410)` + `ReadProcessMemory`；**永不**写进程内存、不注入、不改游戏状态。
2. **偏移表只有一份**：字段偏移 / 注解是**运行时从知识层读**的，不抄进代码 ——
   否则知识层与代码会各自漂移（旧仓的教训：字段引用至少 6 种记法并存，归一化后只有约 1/4 能回连真源）。
3. **锚点锚 EA**：探针输出的定位信息必须锚二进制 EA，而不是反汇编语料行号。

## 6. 迁移批次

**M7**（无强依赖）。
