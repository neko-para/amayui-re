# TITLE 的 Option 按钮（宿主脚本化输入：平台边界替身，⛔ 不是引擎语义）。
#
# 坐标是 1280×720 的虚拟屏坐标；按钮中心来自 `apps/emulator-cxx/title-frame.png` 的人工定位。
# 语义链（都是**引擎脚本自己**的行为，宿主只提供"当前光标 + 当前按钮位图"）：
#   0x109 读光标 → 0x12e 命中框表 → 0xa1/0xa2/0xa3 菜单分派 → 0x3 call-script 52（CONFIG.BIN）。
#
# ★ 四条经验（都由实测得出，改这份文件前先读）：
#  1) 左键 = 引擎**位 0**（`down 0`）；位 1 是右键，TITLE 拿它走另一条支。
#  2) 第一条 `move` 之前光标"不可用"（`0x109` 写 −100000）；TITLE 自己的输入环要先跑完一段
#     装载/淡入才轮到 `0xcd` 派发回调。`--anchor-script 21092` 让本文件的毫秒从**进入 TITLE 那一刻**起算。
#  3) 命中测试只在**坐标变化**时跑（TITLE 自己比较上一步的 x/y）⇒ 这里故意先停在 Option 右侧
#     （900,622，不在框内）再搬进 (812,622)："变化"一定发生在输入环里，不依赖 setup 用了多久。
#  4) 点击在**抬起**时生效（`0x108` 位图的边沿由脚本自己保存上一次），所以 down / up 分成两条、
#     相隔至少一个 tick（同一毫秒的 down+up 会被一起应用，脚本一次也采不到"按下"）。
