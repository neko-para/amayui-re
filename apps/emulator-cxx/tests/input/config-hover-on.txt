# 设置界面（CONFIG1.BIN 20940，系统设定页）：光标**停在**右侧第一行 ON 按钮上。
# 用途：CTest `emulator-core-config-hover-hit` —— 判据是脚本自己的命中查找（局部格 0x7de）
# 必须给出一个**非负**项下标；修复前它恒为 −1（右列控件永远命中不到）。
#
# ★ 为什么每个位置要两条 `move`：这个界面**只在坐标变化时**跑命中查找（脚本自己比较上一轮 x/y），
#   而且从 TITLE 进设置界面的头几百毫秒它还在走"装载后第一次布局"，那一次移动会被吞掉。
#   两次相隔 200 ms 的移动保证至少有一次落在输入环里。
# ★ 坐标是 1280×720 虚拟屏坐标。右列第一行 ON 的命中框 = x∈[970,1056]、y∈[102,138]。
