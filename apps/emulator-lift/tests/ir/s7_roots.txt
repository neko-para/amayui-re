# S7（D53）的**活体判据**根集（`lift-s7-structured`）—— 一行一个 hex EA
#
# 只放一对：**调用者 F** 与它 `call rel32` 的**被调方 G**（两个都是单元根 ⇒ 两个分量）。
#   0x4C0980   F：`push 0x4C0985; call G; …; ret`（`call` 的 resume 在 F 自己的分量里）
#   0x4C0210   G：`xor` 一族 + `ret`（把 `[esp]` 弹出的返回 EA 原样交给宿主 `ret`）
# ★ 选择判据（可复核）：`lift_aot.ll` 里 `lift_cc_4C0980` 的体内有
#   `%t5 = call i32 @lift_cc_4C0210(...)` + `icmp eq %t5, 4983173(0x4C0985)` + `br %s7_ok_0`
#   ⇒ F 的 `call` 已经是**宿主 call**、G 的结尾是 `ret i32 %t38`（**宿主 ret**）。
# ★ ⛔ 不要往这里加"随便挑的 EA"：测试体会①线性解码找 `call rel32 G`、②断言 `lookups == 1`
#   （整段一次派发跑完）、③把 guest 栈的 `esp` / `[esp]` 与解释器臂逐位比。加错了就是红。
