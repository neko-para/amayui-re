# 2026-11-15 **本轮新增 inline 族**的两臂差分根集（一行一个 hex EA；`#` 起注释）
#
# 用途：`lift-ops-diff`（`tests/ops_diff.cpp`）用这份根集让 `emulator-lift-gen` 生成一份
# **只含这些 EA 的**模块；测试体对每个站点从同一份受控状态出发跑两臂并**逐位比较**：
#   ① **lifted 臂**：`lookup(ea)` 拿生成代码，跑到"回到表外 EA"或预算用尽；
#   ② **解释器臂**：同一份状态，`Machine::run(max_insns = lifted 侧实测条数)`；
#   ③ 比较：8 GPR / EFLAGS / 8 个 x87 槽（double 位型）/ top / tag / 状态字 / 控制字 /
#      8 个 xmm（16 字节）/ mxcsr / 一段 guest 内存（1 KiB）。
#   ④ 停机类（`div` 除零 / 商溢出、`idiv` 除零 / 商溢出、`int`、`xlat`）：两臂都必须停，
#      且 `stop_why` **字符串相同**（= 同一条停机面），状态逐位相同。
#
# ★ 为什么这些 EA：每个都是**该 op 在语料里的真实站点**（`.ll` 的 `; lift_one @ <EA>` 注释
#   按 op 分组列出来的），⛔ 不是编造的字节。
