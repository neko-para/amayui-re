## 帧与调用

脚本在一个**帧**里执行：帧记录当前脚本的代码区起点、指令指针、局部池与一条**返回栈**。本章规定**帧栈**这一结构：帧的容量与编号、当前帧、父帧链、帧的分配与释放。各条控制转移指令的逐条效果（调用 / 返回 / 条件跳转 / 换脚本 / 结束当前脚本 / 重置）见「指令语义」。

★ **位置** = 同脚本内按 32 位字编号的下标（基 = 代码区起点，与「脚本与执行」的三张子表同一口径）。位置**不是字节偏移**，也不是文件 id；`位置 × 4` 才是字节偏移。调用（`0x8f`）与返回（`0x5`）**共用**这一量：调用把「下一条指令的位置」压进本帧返回栈，返回把弹出的位置还原成字节地址 `代码区起点 + 4 × 位置`。共用的是**单位与基**，不是帧记录的同一格；其他把位置当操作数或字段值的指令也用同一单位与基。

★ **两种下标是两个命名空间**：位置（代码字下标，以代码区起点为基）与池下标（槽在池内的序号）互不相干；本规范不会把一个当另一个用。**指令指针不是代码字下标**：它是字节地址，与位置之间按 `代码区起点 + 4 × 位置` 换算。

★ 本版不规定：**装载帧**（把脚本装进一个按槽号指定的帧，`0x6`）与**换帧**（切到按槽号指定的已装载帧，`0x8`）；脚本头 / 池的具体布局见「脚本与执行」「数据池」。

### 引擎里的脚本帧栈

<!-- rule: CORE-FRAME-STACK -->

引擎持有一组脚本帧：**定长数组，按"帧号"索引**（`0..39`）；**当前帧号**指出谁在跑。

- 帧的数量上限是 **40**（帧号 `0..39`）：**当前帧号 = 39 时再换脚本就报错**（报错文本是"最大 40"）；超限是**错误**（不是静默失败）。上限按**帧号**判定，不按"已分配了几个槽"——换脚本的新帧号恒为「父帧号 + 1」，与已占用的槽数无关。
- 每个帧**至多有一个父帧**（记在帧记录里，记的是**帧号**）⇒ 形成一条父帧链；根脚本的帧没有父帧：它的父帧号是哨兵 **−1**（32 位全 1，表示无父帧）。
- **父帧号 = 调用发生时正在执行的帧号**：因此「父帧号 + 1」与「当前帧号 + 1」是同一个槽号，两种写法指同一件事。
- **换脚本**占用「父帧号 + 1」那个槽并成为当前帧：该槽原有的内容被释放（不因该槽已被占用而报错）。**结束当前脚本**把当前帧号改成**记录里的父帧号**（不是"弹栈"），父帧号为 **−1** 时整个执行结束。**全局重置**丢弃全部 40 个帧槽、帧号回 0、父帧号回 −1，并以统一文件 id 0 重装根脚本，从它的 dword 0 开始执行；重置同时改写其他引擎级状态：已取证的复位项见「指令语义」的 `0x9` 条目；其余子系统复位入口本版不规定。
- **结束当前脚本时有条件地释放**：只有「父帧号 + 1 == 当前帧号」才释放当前帧槽（代码区缓冲与各数组）；否则不释放，只切帧号。切完之后从父帧号起**向下（帧号递减）**扫描，跳过**空槽**（该帧没有装载脚本：判据是该帧的代码区起点为 0），直到遇到一个非空槽；帧号降到 0 以下仍为空 ⇒ **错误**。
- 每帧各自持有：代码区起点、指令指针、局部池、返回栈（这些都属于帧，不共享）。

**状态对应**

| 领域状态 | 机器状态 |
|---|---|
| 引擎持有的一组脚本帧 | 定长的帧区（**容量 40**）+ 每帧一条记录 |
| 谁在跑 | 引擎级的"当前帧"选择子 |
| 父帧链 | 每帧记录里的父帧号 |

**成立条件**

- 当前帧号 = 39 时再换脚本必然报错（文本"最大 40"），因此上限是可观察的；报错条件与"已占用了多少个槽"无关。
- 帧是**有限资源**：释放按上面的条件发生；释放后的槽不搬移、不压缩，它重新被使用时仍是同一个帧号（新帧号由「父帧号 + 1」决定）。
- 局部池、返回栈、指令指针**按帧独立**：这是"帧"这个概念的实质，不是实现优化。
