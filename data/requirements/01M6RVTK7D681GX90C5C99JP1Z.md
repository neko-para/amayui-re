## 目标

boot 首帧 profile 的第 2 / 第 3 个 guest 热点 —— `sub_429020`（关 override 750 ms）与
`sub_48AE90`（663 ms）—— 做成**函数级** native override：默认进 `--native-overrides all`、
保持解释器回退、有 pure 差分守卫，并用真实 boot A/B 验证首帧逐位不变。

## 取证（锚 = EA）

- `sub_429020`（`.lst` 0x429020..0x4290EC，`__thiscall retn 8`）= `Map::findIndex(hash, key)`：
  - 表**指针**在 `[this+0x18]`（0x42902D `mov ecx,[ecx+18h]`，⚠ 不是“表在 this+0x18”）、
    容量在 `[this+8]`（0x4290A5 `div dword ptr [ecx+8]`）；槽 28 B = MSVC `std::string`
    （`len@+0x10` / `cap@+0x14`；cap<16 用槽内 SSO，否则 `[slot]` 是堆指针）。
  - 空槽判据 `len==0`（0x429039 / 0x4290B6）；**先**判第一个槽空再算 strlen。
  - 命中 = 先 `sub_401000(slot, key, min(len,keylen))`（0x429084 调用）**且** `len==keylen`
    （0x429090..0x4290E4 `cmp esi,edi; setnz`）；不中 `index=(index+1)%capacity`（0x4290A2）。
  - 返回 index / `-1`（0x429046 / 0x4290DA `or eax,-1`）。
  - 优化点（语义不变）：guest **每个探测**都重算 `strlen(a3)`（0x429057 / 0x4290C6）⇒ 宿主只算一次。
- `sub_48AE90`（`.lst` 0x48AE90..0x48B087，`__thiscall retn 0Ch`）= `NormalTexture` 虚表第 6 项
  （`??_7NormalTexture@@6B@` @0x528c00）= `Fill(rect, color888, alpha)`：
  - 对 `[self+0x40C]` 的纹理 `LockRect(rect)`（vtable +0x4C，0x48AEAF）；失败原样返回 HRESULT。
  - 位深 = `ds:dword_5518C0`（0x48AEBC `cmp ds:dword_5518C0,10h`）。**唯一**写点是 0x406B14
    （`mov ds:dword_5518C0, eax`，值来自配置 `display:TextureBit`）⇒ ⛔ 不是 DDraw 的显示 bpp
    （第一版按 `ddraw::displayMode` 写，恰好在 A/B 里同值，看不出来）。
  - 16bpp：`R4<<8|G4<<4|B4`；`alpha>=0` 时 A4 = alpha 高 4 位（0x48AF59）；
    `alpha<0` 时 `& 0xF000` **保留**原 A4（0x48AF35）。
    ⚠ 行步进：`alpha>=0` 是 `2*((pitch*row)/2)`（0x48AF76），`alpha<0` 是 `2*((pitch*row)/4)`
    （0x48AF16）= **pitch/2**，逐字照抄，⛔ 不要“顺手修正”。
  - 32bpp：`4*((pitch*row)/4)`（0x48AFE0 / 0x48B037）；`alpha>=0` ⇒ `(alpha<<24)|(color&0xFFFFFF)`；
    `alpha<0` ⇒ `(color&0xFFFFFF)|(old&0xFF000000)`。
  - 0x48B06C 起 `UnlockRect`（vtable +0x50），然后返回 0（不检查 unlock 结果）。

## 实现

- `src/runtime/native_overrides.{h,cpp}`：`nativeFindIndex429020` / `nativeFill48AE90`；
  纯像素核 `fillRect16` / `fillRect32`（只碰宿主缓冲）。`NativeOverrideTable::kMax` 8 → 12。
- 两项都 `debug=false` ⇒ 进 `all`，`-名字` 可排除。
- 429020：只读 guest 内存；`this`/表/容量 0、`index>=capacity`、4 GiB 越界、safe mode 未提交 ⇒ 回退；
  **整表没有空槽**时 guest 会死循环 ⇒ 回退（⛔ 不编造 -1）。
- 48AE90：所有前置条件（矩形 / 纹理 / 位深 / 范围 / 提交）在**加锁前**判完；加锁后只用
  `lockRect` 返回的 pitch/pBits（与预测核对一次），失败/不一致 ⇒ 解锁后回退，不留锁/半状态。

## 守卫（会红）

- `tests/native_override.cpp`：
  - 429020：golden model 差分（SSO 串 / 20 字节堆串 / 探测链 / 长度不等但前缀相同 / 空 key /
    整表满 ⇒ 回退 / 首槽空且 key 指针非法 ⇒ -1 / 只读断言 / safe mode 未提交 / `this`·表·容量·index 闸）。
  - 48AE90：像素核四条分支的**手算逐字节**（含 `pitch/2` 那条）、真纹理夹具下**整张 arena 逐字节**
    + 锁记账（locks/version/locked）+ 回退无半状态（空矩形 / 越界 / 纹理 0 / 已锁）。
- `tests/native_override_assets.cpp`（assets 档）：从 `AGE.EXE` 取 `sub_401000` / `sub_429020` /
  `sub_48AE90` 的**真字节**，同一夹具跑解释器 vs override，比内存 / EAX / ESP / 标号寄存器 / EIP；
  48AE90 还比整张纹理逐字节 + 锁记账（含“纹理 bpp ≠ dword_5518C0”的交叉情形）。
- 变异验证（已做）：16bpp 行步进改成 `pitch` ⇒ 核逐字节用例当场红。
