## 缺口

`docs/03-emulator/platform-effort.md` 两处把 Live2D 在 TITLE 的足迹写成 **0 次**（§3.8 的 "title / option / sn0000 三条足迹里执行 0 次"、
§6 的 "1 / 3 / 1 / 1 次（title 0 次）"），而 2026-11 的实测是：TITLE 有 3 张 PNG 纹理、每帧 `CreateStateBlock` +
声明式 Draw。⇒ 该文档的读数会把人引向"TITLE 不碰 Live2D"的错误结论。

## 判据

- 按**可复跑的命令**重测足迹（哪条命令、哪份 `.lst` / 哪个 `--profile` 口径），把两处读数改成实测值，并写清口径四件事（build 类型 / 平台 / 有无安装 / 日期）。
- 文档里不再出现"title 0 次"这类与实测相反的断言；⛔ 不写状态/进度。
- 若重测后发现原口径（"Live2D 只在 ADV"）指的是**别的 opcode**，那就把主语写清楚（哪个 opcode / 哪个函数），别只改数字。
