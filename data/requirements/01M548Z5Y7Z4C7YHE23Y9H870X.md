## 关键证据（修之前的坏行为）

`sub_429460`：
```
0x429491  mov esi, ecx             ; esi = obj0
0x429493  mov [ebp+var_354], esi   ; 溢出
0x429604  mov esi, [ebp+var_354]   ; catch 块里读回（唯二引用在 .data 的 SEH 表里 ⇒ 静态无入边）
0x42960A  lea edi, [esi+8]         ; = obj0 + 0x8      ← T0+0x8 已声明
0x42961E  lea ecx, [esi+0A609Ch]   ; = obj0 + 0xa609c  ← T0+0xa609c 已声明
```
⇒ 早先这些站点全是"未解析基址"；现在读回的 `esi` 若在**同一进程内**能接上，就按 obj0 判；
**跨 SEH 边界**那一段（静态无入边）用 `{kind:"local", fn:"sub_429460", reg:"esi", span:["0x429604","0x42981e"], type:"T0*"}`
—— ⛔ 不是编一个匿名类型（那等于把 obj0 写成假类型）。
