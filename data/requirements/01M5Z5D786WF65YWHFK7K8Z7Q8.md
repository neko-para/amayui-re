## 结论：设置界面的两条症状都由**缺指令 / 错用取址原语**造成，已落地并有守卫

### 症状与根因

| 症状 | 根因 | 判据（会红） |
|---|---|---|
| 右侧按钮**悬停**全部无反应 | 数组族五条指令把「数组基址 / 目标地址」当成**槽地址**（`address_of`），而规范要求**取址原语**（`address_of_operand`）⇒ 指针族的落点被写进指针槽。命中表因此一个框都没建出来，`0x12e` 恒返回 −1 | `emulator-core-config-hover-hit`（ON 上命中 ≥ 0 且 正文里 −1，两半一起） |
| 右侧按钮**点击**无反应 | 点第一行 ON/OFF ⇒ `0x2cf` 没有 handler ⇒ `opcode-not-implemented` **停机** | `emulator-core-config-toggle`（点 ON / 点 OFF 的配置快照必须不同且 OFF ⇒ 0） |
| 部分页面**一滚动就停** | 滚动触发**整页重建**，重建读「自动消息显示时长」两档 ⇒ `0x1b8` 没有 handler ⇒ 停机 | `emulator-core-config-pages`（六页各：页内命中项数量对得上 + 滚 6 格无停机） |

★ 顺带发现：旧的 `emulator-core-tab-*` 判据**恒真**（只查"还在 20940 里"，而坐标整体偏了一个 tab ⇒
点到的是隔壁 tab 也仍然绿）。已换成「页脚本 + 页内命中项数量 + 滚动」，旧测试删除。

### 本批补的指令（都有取证锚，EA 在代码注释里）

`0x2cf`（显示模式请求：只有目标 ∈ {0,1} 才转发；三条早退都不写键；写 `display:ScreenMode` =
归一键值）· `0x307`（命名键 `system:EffectSkipOnClick` 的原值写；**缺键不建键**）·
`0x1b5`（`message:MessageSpeed` + 参数格同值写）· `0x1b8` / `0x1b9`（`AutoMessageTime0/1` 的读 / 写；
越界只记日志、**不写落点**）· `0x1ba`（声道 1..4 → 四个 `sound:*` 键，四支语义各不相同）·
`0xb6` / `0xb7` / `0xb8` / `0xba`（音频请求：槽资源格 / BGM 三格 + 请求计数）。

### 还没做完（**新开单**，不要以为收口了）

1. **`0x198`**（argc 3，handler `sub_41FE10` → `sub_456400(Engine+0x14D30, op1, op2, op3)`）：
   在设置界面里点「?」「初期化」这类会开**文本窗**的控件才走到。缺取证（文本窗那套 `+0x550/+0x554/
   +0x35598` 的语义在 `0x82` 的报告里也只是部分）。**复现**：
   `--play-headless --input-script .tmp/probe/walk-b.txt`（点六页的前四行 × ON/OFF/? × 滚轮），
   `--sweep-missing` 会报 `missing 0x198 hits=1`。
2. **`0x14b` / `0x14c` / `0x14d`**（handler `sub_4229D0` 等）：点「执行自动保存」那类行会进脚本 51（存档路径），
   随后撞 `0x1a0 save-host-missing` —— 后者是**已知 seam**（headless 没注入 `SaveHost`），
   所以这三条即使补了也还要先解决 seam 才能收口。
3. **脚本键持久化**：多数 ON/OFF 行走的是 `save-int (global-int …)` = 写**脚本键表**，再由启动期绑定
   落到命名键；当前 `config script=0`（一条绑定都没有）⇒ 点它们**不会**改 `SYS4REG.INI`。
   这是「按钮点了没反应」的**另一半**，与本批缺指令无关。
4. **内建默认值未建模**：引擎在构造期登记 `message:MessageSpeed=5`、`AutoMessageTime0=500`、
   `AutoMessageTime1=2000`、`sound:SE/Voice/Movie=1`（EA `0x491d4d` / `0x49201c` / `0x492039` / `0x491932` 等），
   本仓 `ConfigStore` 缺键给 0 ⇒ 设置界面初值与真机不同（`0x1b8` 读出来是 0 而不是 500/2000）。
5. **spec 条目还没写**：本批 9 条规则的正文 / `bindings` / `audit` 只有取证报告里的草案
   （`CORE-OPS-FORWARD-DISPLAY-MODE`、`CORE-OPS-FORWARD-NAMED-KEY`、`CORE-CONFIG-NAMED-WRITE`、
   `CORE-CONFIG-NAMED-AUTOTIME`、`CORE-OPS-AUDIO-MODE`、`CORE-OPS-AUDIO-SE-STOP`、
   `CORE-OPS-AUDIO-BGM-RESTART`、`CORE-OPS-AUDIO-BGM-STOP`、`CORE-OPS-AUDIO-WAV` 的补充段），
   **没有落进 `data/spec/`** ⇒ `pnpm tools spec report` 的 opcode 缺口不会缩小。
6. **`0x82`**（画一段文本，argc 5）与 **`0x2f5` / `0x2ff`**（语音槽 / 组请求）、
   **`0xc2` / `0xc4`**（BGM 音量淡变 / 语音播放）：取证齐了但**未实现**（`0x82` 要接文本源对象表，
   `0xc2/c4` 要 `Music` 对象与 FadeTimer）。当前页面路径不经过它们。
