## 一句话
`IDirect3DDevice9` 的 fixed-function 渲染流水线已落地（设备状态机 + 软件光栅 + 顶点变换 + 纹理采样 + 混合 + `Present`），
判据 `tests/d3d9_pipeline.cpp`（224 checks / 8 组、顶层 pure）。boot 因此从 `SetTransform(+0xB0)` 的 trap 前进了约 **9.2M 条指令**
（103,059,958 → **112,255,445**），并在设备建好之后撞到**另一个子系统**的缺口（条件 B 停手）：见「当前卡点」。

## 已实现（槽号 / 偏移 / 语义）
- `#44 +0xB0 SetTransform(State, *D3DMATRIX)`：`D3DTS_VIEW(2)` / `PROJECTION(3)` / `WORLD(0x100)` 存取一致；
- `#41/#42 +0xA4/+0xA8 BeginScene/EndScene`：配对校验（未 `BeginScene` 就画 ⇒ 真机 `D3DERR_INVALIDCALL`）；
- `#57 +0xE4 SetRenderState`：`ZENABLE` / `ZWRITEENABLE` / `CULLMODE` / `LIGHTING` / `ALPHABLENDENABLE` / `SRCBLEND` /
  `DESTBLEND` / `ALPHATESTENABLE` / `ALPHAFUNC` / `ALPHAREF` / `COLOROP` / `COLORARG1/2` / `TEXTUREFACTOR` /
  `SCISSORTESTENABLE`；**非法枚举值 ⇒ `D3DERR_INVALIDCALL` + 日志**（⛔ 不静默吞）；
- `#65 +0x104 SetTexture` / `#69 +0x114 SetSamplerState`（`MINFILTER`/`MAGFILTER`/`ADDRESSU`/`ADDRESSV`）；
- `#73 +0x124 SetFVF`（顶点格式：`POSITION`/`DIFFUSE`/`TEX1` 的常用组合）；
- `#81 +0x144 DrawPrimitive` / `#82 +0x148 DrawIndexedPrimitive` / `#83 +0x14C DrawPrimitiveUP`（引擎实际调到的那些）；
- `#17 +0x44 Present`：后缓冲 → `HeadlessPresenter`（`frameCount` / `lastHash` / 帧号日志）。

**光栅 / T&L 口径**（⛔ 是自洽近似，不冒充真机）：
顶点经 `WORLD → VIEW → PROJECTION` 变换 + 视图体裁剪 → 屏幕映射；三角形用**重心坐标 + 边界规则**填充（⛔ 不是"填包围盒"，
否则像素判据不可信）；纹理按 `SetSamplerState` 取最近点；`ALPHABLENDENABLE` 时 `out = src*a + dst*(1-a)`；
`ZENABLE/ZWRITEENABLE` 按状态开关。**未做**：光照计算、`SetStreamSource` 的非 UP 顶点流、多纹理阶段、
`D3DFVF_XYZRHW` 之外的裁剪空间细节、mipmap 采样 —— 都保持 loud trap 或明确拒绝。

## 当前卡点（★ 下一单的输入，属**文件与路径**族，不是 D3D）
boot 现在跑到 **112,255,445** 条指令后由 **`ExitProcess(0)`** 结束，直接诱因是一次**版本读取失败**：
```
[d3d9] Direct3DCreate9: SDKVersion=32 ⇒ IDirect3D9 对象 0x101C5E10
[shim] version!GetFileVersionInfoSizeA: VFS 解析不了 "E:\Games\Eushully\天結\AGE.EXE"
       （[notdir] 段 "Games" 在 "E:\Projects\amayui-re\links\install" 里不存在）⇒ 返回 0 + 错误 2
[shim] user32!MessageBoxA: 模态 no-op ⇒ 返回 IDOK(1)
[shim] kernel32!ExitProcess: guest 请求退出：exit_code=0
```
- 引擎在做**自检**（读自己的 `FileVersion` 与 `set:Version` 比）；它给的路径是 guest 根下的绝对路径
  `E:\Games\Eushully\天結\AGE.EXE`，而 **VFS 的 `resolve` 只认"相对路径 / `C:\Users\Amayui\…`（appdata）/ 无盘符前缀"**，
  **不认 guest 根前缀** ⇒ 把 `Games` 当成 `--game-dir` 下的第一段 ⇒ 失败。
- ⚠ 日志里 `天結` 显示成 `?V??` 是**日志把 CP932 字节直接写进 UTF-8 流**的显示问题（guest 侧编码已由
  `REQ-01M6KV37P6QACK6XPQRCPT23B2` 修正），不是路径本身坏 —— 但这条日志确实应该转码后再打。
- ⇒ **下一单**：让 `Vfs::resolve` 把 `<guest_root>\…` 映射到 `--game-dir\…`（与"相对路径"等价），
  并让日志按 UTF-8 打印 guest 路径。判据：`version!GetFileVersionInfoSizeA("E:\Games\Eushully\天結\AGE.EXE")` 成功
  （overlay 命中拆壳件），boot 继续往下走。
