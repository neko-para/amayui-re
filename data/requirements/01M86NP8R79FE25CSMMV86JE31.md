# AOT · COM trampoline 去税：`SetRenderState` / `SetSamplerState` 再砍一半

## 一句话

shim 固定税那一批（`200ab91`）把 `SetRenderState` 775.7→**429.4 ns/次**、`SetSamplerState` 807.3→**500.7**，
但 COM 接口调用还多付一层 `ComRegistry::dispatch`：**每次调用在锁内拷两个 `std::string`**
（`iface` / `name`）+ **两次哈希查找**（`methods_` 与 `objects_`）+ 一把 `recursive_mutex` ——
而这两个名字**只用于"`this` 不是我们建出来的对象"那条诊断日志**。

## 读数（2026-11-23 / SAVE11 8 s 窗口 / 5 趟中位）

| shim | 现在 | 目标 |
|---|---:|---:|
| `IDirect3DDevice9::SetRenderState` | 429.4 ns | **~200 ns** |
| `IDirect3DDevice9::SetSamplerState` | 500.7 ns | **~250 ns** |
| 调用量 | 1.03 M / 290 K 次 / 8 s | — |

## 方案

1. **名字只在要打日志时取**：`dispatch` 里不再 `iface = e.iface; name = e.name;`，只保留
   `const MethodEntry*`（`unordered_map` 节点稳定）；`!known_this` / `!fn` 这两条罕见路径再取字符串。
2. **`methods_` 换按槽下标的平坦数组**（stub 形状恒为 `shim_page + slot*4`，已有 `byStubEa` 的先例）；
   哈希表只留给"表外 stub"的兜底。
3. **`known_this` 只在 Debug 可见时判**（它只喂一条诊断日志）；或换成对象地址的小位图。
4. **锁**：`recursive_mutex` → 只在注册/建对象时写的读多写少结构（读侧不加锁，或 `shared_mutex` 读锁）。
5. 顺带：`comUnsupported` 的名字解析保持原样（失败路径，无所谓）。

## 判据

- **主判据**：`SetRenderState` / `SetSamplerState` 的 **ns/次**（同一 boot/SAVE11 窗口、5 趟中位）；
- 五项指纹（`exit` / `stop @` / arena / `table misses`）逐位同；
- 既有 COM/D3D CTest 全绿（`d3d9-*` / `d3dx9-*` / `com-*`）；`ctest` / `pnpm test` / `pnpm verify`；
- 守卫：`known_this` 诊断仍能触发（构造一个非本 registry 的 `this` ⇒ 仍打那条日志）；
  变异：把名字取回路径改回"每次调用都拷"⇒ 一条源文本/结构守卫红（或可判地回退到"每调用两次 string 拷贝"）。

## 边界

- ⛔ 不改 COM 的对外语义（vtable 槽、QI、引用计数、错误码）。
- ⛔ 不引入运行期 override 表（§12.8）；这是 shim 内部实现。
