## 本轮改了什么（摘要）

- 10-format：版本串比较口径（4 字节无符号 C 字符串比较、阈值 `"080 "` 是引擎常量、本作语料 `"450 "`）；子头短/长行为；长度槽"谁写"分类（直线 / 控制转移）；opcode 域靠 `hasHandler` 列判 30 条缺省；执行结束的主语限定为静态解码。
- 15-frame：范围收窄为帧栈；深度判据 = 当前帧号 39；空槽判据（代码区起点 = 0）与向下扫描；`0x6` = 装载帧（不是换帧）、`0x8` = 换帧（两者本版不规定，各挂残差）；指令指针 = 字节地址（`base + 4×位置`）。
- 40-pools：容器句柄纳入本版；写路径没有元素下标（删"下标检查会抛"）；key 来源（时间种子 → rand 非 0 → 唯一写入点）；字符串记录 +0x14 容量 / +0x10 长度；SSO 阈值 16 是常量；全局计数来自初始化文件头部（不是脚本头）。
- 50-engine-state：0x30a / 0x107 / 0x10b 三条检查的比较是**无符号 above**（负值必抛/跳过）；异常类别与"显示消息异常"对齐。
- 55-config：键取"引用槽里的地址 − 全局族池基址 ÷ 元素宽度"；玩家文件段名/键名**字节精确**；默认表收尾修补落到 `set:Menu_Save` 与 1/10 的值；注释符无语义（只有段头与键值两分支）；行缓冲 256。
- 60-ops：起色 = 排窗时的当前颜色；`0x32f` 作为转发族的显式例外；`0x88` 两个格；`0x2` 不写长度槽 + 返回记号 −1；`0x9` 复位清单；`0x70`/`0x79`/`0x1c1` 记录不存在 ⇒ 直接解引用；章首清单改成 39 规则 / 45 opcode 的闭集；`0x320` 的 2..8 全按地址读（旧文写浮点是错的）。
- 70-vm：迭代顺序固定为"泵 → 读钟 → 交付 → 门"；有动画标记由同一次场景推进置/清；窗到期两条都清位；持续时间为 0 不推进；等待位"清不清由服务分支决定"。
- 20-alf / 30-agf：定义"段"；AC 的 12 字节块 [268,280)、压缩数据 280 起；LZSS 位置 = 环内下标、长度 = 低 4 位 + 3；TOC 两种记录宽度；AGF v2 **必需** ACIF（紧接 body，无 2048 搜索）；调色板 `2^bpp` 项、行不填充、bottom-up。
- 结构：`format/opcode-table.json` 增 `hasHandler`（574 条 / 544 / 30）；`spec describe` 的 storage 只列 shape、configKeys 补 `ini[].if` / `extra.from`；README 明确 ALF/AGF 两章"协议描述、不挂规则"。
