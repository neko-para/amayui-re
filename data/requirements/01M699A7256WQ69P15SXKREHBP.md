# 核 Font+0x548：45 处读点的载体一致性、整块拷贝与模板初始化（决定是否 discarded）

- 要收口的残差：`RES-OPS-FORWARD-PROLOGUE-BIT2`
- 所属规则：`CORE-OPS-FORWARD-PROLOGUE`
- 入口 EA：`0x46511a`（构造器写 0）、`0x464fd0`（字体对象构造器）；读点见下

## 已经知道什么（带 EA）

- 字体对象构造器 `0x464fd0` 在 `0x46511a` 写 `[esi+548h] = ebx`，同一串里 `ebx` 是 0
  （同串把 `ebx` 当三个 NULL 指针实参用）。
- 全语料对该偏移的**写点扫描**（`rg "548h"`，57 处访问）只有三处写形态：
  `0x46511a`（字体构造器，写 0）、`0x4155c1`（`sub_4155B0`，另一个对象）、
  `0x48db40`（`sub_48DB10`，另一个对象）；`0x40472c` 是 `sub_404710` 里的 `lea`（`MIXERCONTROLDETAILS`，另一个对象）。
- 读点分两族：字体 / 文本绘制族（`0x455db9`、`0x456259`、`0x45afd9`、`0x45b524`、`0x45c09c`、
  `0x4608eb` … `0x473d23` 这一带）与另外几族（`0x48db20` 等）。
- 位 2 的另一半已定：`Font+0x55C`（`0x78` 写的绘制模式）在同串被当 NULL / 整型用，
  与本格不是同一格（`0x4691a6` 把 `+0x55C` 原样当标志传）。

## 还缺什么

- **载体一致性**：45 处 `cmp [reg+548h],0` 的基址是否**都是同一个字体对象**。若混入别的类，
  「Font+0x548 恒 0」就不成立，不能据此判死支。
- **整块拷贝 / 模板初始化**：字体对象（`Engine+0x14D30`，`0x464fd0` 构造）有没有
  `rep movsd` / `memcpy` / `operator=` 把一块模板搬进来（那会绕过构造器的 0）。

## 判据（什么算做完）

1. 逐点给出 45 个读点的**基址来源**（同一 Font / 其它类 / 解不出），并给出计数；
2. 给出字体对象**无整块拷贝**的否定证明（或找到拷贝点并说明它写什么）；
3. 若两项都成立 ⇒ 按 S3a 改成 `discarded`（该格在语料内恒 0，非 0 支不可达），
   并在 `reason` / `range` / `impact` 里写清；否则保留 `unknown` 并把下一步写死。
