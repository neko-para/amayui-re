## 已落地（2026-10-29）

spec `62-adv-text.md` 的 `ADV-TEXT-APPEND` 已写入算式，实现按它改了 `draw_text_layer_text`：

- **格** = 本条主文本**最后一行**占的范围（左端 = 该行起点，宽 = 该行排完后的宽）；折行时重置行起点。
- `W` = 振り仮名整串量度宽、`n` = 假名数 + 1（= ⌊(字节数 + 3) ÷ 2⌋，含两端边距）、`d` = 格宽 − W：
  - `d > 0` ⇒ 每档步进 ⌊d ÷ n⌋；首字 x = 格左 + 步进；每个假名在自身量度宽外再各加一次步进
    （2 字节整份、1 字节半份）⇒ 两端各留一份、恰好铺满格宽；
  - `d ≤ 0` ⇒ 不加步进，首字 x = 格左 − ⌊|d| ÷ 2⌋（整串以格中心对齐）。
- 振り仮名现在**逐假名**排条目 / 入待画队列（原先整串一个条目）。
- 守卫：CTest `emulator-core-adv-ruby`（`--only-ruby`）两档几何断言（只用条目矩形，不依赖字体量度）：
  ① 8 主字 × 3 假名 ⇒ 左缩进 > 0、左右缩进相等、假名之间间距 = 两端边距（铺满格宽那一支）；
  ② 1 主字 × 5 假名 ⇒ 左侧伸出 > 0 且左右伸出量相等（居中那一支）。
  变异（把步进写成 0 = 旧的左对齐）⇒ `振り仮名仍贴着格左（左对齐）` 当场红。

## 剩（`RES-ADV-TEXT-APPEND-RUBY`）

1. **跨行 / 多段**时"格"怎么取：调用方在换行分支与段尾各调一次（`0x46c37f` / `0x46cba0`），两次的格可能不同；
   本实现统一取"最后一行"，没有区分这两个调用点。
2. 「每行分到几个假名」的比例切分（`0x46c2ed`）本实现**没有**：现在是把整串假名按上面的算式摆进最后一行。
3. 纵向那个条件性 `+1`（`dword_55e1bc+667856` 与 `Font+0x355e8`）未实现。
4. `W` 用 A 支设备字重量、字形用 B 支画 ⇒ 字号比差是否补偿未查清。
