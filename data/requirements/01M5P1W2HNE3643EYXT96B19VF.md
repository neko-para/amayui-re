# 🐞 影片帧的颜色键哨兵被当成白键（白闪 / logo 边缘黑噪点）

## 症状

- 启动约 1s 整体白屏闪一次（跳过 logo 也一样）。
- 影片中后段静态画面（白底 + 洋红 logo）在 logo 附近出现黑色噪点。

## 根因

`apps/emulator-new/src/platform/electron/renderer/pixi-host.ts` 的上传路径曾把"无颜色键"判据从 `color >= 0` 改成 `color !== 0`：

- 影片帧上传传的是 **`color: -1`**（调用方的"无键"哨兵）；
- `-1 >>> 0 = 0xFFFFFFFF`，于是 `applyColorKey` 把影片里**所有纯白像素**（白底、logo 抗锯齿边缘）清成透明（RGB=0, A=0）；
- 透明黑经线性过滤与后面的合成 ⇒ logo 边缘黑噪点；整帧白底被清掉时表现为一次白闪。

## 修复

- `core/agf.ts` 新增纯函数 `hasColorKey(color): boolean`：**只有正数才是键**；`0` 与 `-1` 都是无键哨兵。
- `pixi-host.ts` 改用 `hasColorKey(color)` 再调用 `applyColorKey`。
- 守卫：`emulator-new-agf` 的"颜色键哨兵"用例；变异"非 0 判据"会红。

## 验证

`pnpm test` 999/0 · `pnpm typecheck` 六工程绿。**需要重建 renderer bundle**（`vite build`）后复测。

## 怎么查

`pnpm tools spec show FMT-AGF-PIXELS`（颜色键的 32 位 ARGB 比较）· `tools/test/emulator-new-agf.test.mjs`。
