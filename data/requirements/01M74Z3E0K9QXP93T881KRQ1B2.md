## 一句话

给窗口模式加一个默认关的**调试叠层**（`--overlay`）：在**画面**左上角叠加当前鼠标位置（与 `click x y` 同一坐标系）和可获得的渲染信息（FPS / 帧号 / 光栅后端 / 呈现模式）。

## 为什么

手写 `click x y` / 录 route 时，坐标只能目测；"这一帧为什么慢 / 现在走的是哪条呈现路径"要另开日志。叠层让"定位坐标"和"确认当前渲染状态"在同一屏完成。

## 判据（实现即契约）

1. **默认关**、只作用于 **`--present window`**（`--present headless --overlay` ⇒ exit 2）。⛔ 不写 guest 内存、⛔ 不改 guest 后缓冲 / 整帧 hash / `--dump-frame`。
2. 坐标系 = **guest 客户区坐标**（与 `click x y`、`--input-script` 一致），形如 `mouse 812,622`。
3. 内容与顺序：`mouse` → `script` → `fps` → `frame` → `raster` → `present` → `worst`。拿不到的整行省略，⛔ 不编数字。
   - `script <名字>`：**当前身份**（marker：`cur` + `files[cur].id` → 引擎名字表反解）；降级写 `script id:0x%08X（降级）`；从未采到身份 ⇒ 整行省略。
     ★ 它答"**当前帧**是谁"，不是"帧栈顶"（栈未取证）。
   - `worst 3s  wall=… guest=… shim=…`：最近 **3 s** 内**每帧**（= 相邻两次 Present 的 steady_clock 间隔）的最大值，与 `LIFT_FRAME_TRACE` **同一份**读数。
     ★ **第一个样本（run 开始 → 第一次 Present）不是一帧 ⇒ 丢弃**，否则 boot 的 ~20 s 会占满开头的窗口。
     ★ `guest` 只在**块计时**打开时有值（`--profile` / profile 窗口）；没有就写 `guest=--`，⛔ 不为它偷偷打开块计时（那会改变被观测的性能本身）。
4. 位置 = **画面**左上角（letterbox 之后那个矩形的原点），⛔ 不是窗口左上角；尺寸 1:1 窗口像素、不随画面缩放。深底亮字，只占该矩形。
5. ⛔ 不引入新依赖（不引 SDL_ttf）；内置 5×7 位图字体画 ASCII 即可。
6. **可见性**：只在**窗口**与 `--present-screenshot` 可见。`--interaction-fail-dump` / `--dump-frame` 写的是 **guest 帧**，**不含**叠层（与"不写 guest"同一口径）。
7. 两条呈现路径（SDL_Renderer / GPU 直出）都要画；文本更新**节流 ≤100 ms**，鼠标位置变化立即更新。

## 守卫

- pure：字体栅格化（逐字位图）、行格式化（给定输入 ⇒ 确定字符串）、**只写矩形**（哨兵缓冲，矩形外逐字节不变，矩形按实际尺寸取）。
- 直出/尺寸：叠层 dst 原点 == letterbox 之后画面 rect 的原点（test-only 窗口尺寸钩子或暴露"上一次叠层 dst"）。
- 窗口 smoke（assets）：`--present window --present-hidden --overlay --max-frames 2` exit 0；去掉 `--overlay` 也 exit 0。
