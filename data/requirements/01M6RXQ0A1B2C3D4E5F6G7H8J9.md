## 目标

按用户裁决的**方案 D** 落地音频：不建第二宿主线程 / 第二 guest 栈；`sub_4B5AA0` 的线程体
native 化（12 段 native + 唯一 guest 调用 `0x4B5B03 call sub_4B6C30`），由 dispatcher 块边界的泵
执行；宿主实现 DirectSound 设备模型（游标 / 4 个位置通知 / 状态机 / 逐缓冲格式 / 混音）与
SDL3 输出。验收：进入 TITLE 后 BGM 连续可听；SE（含 hover）走同一条路径。

## 实现

- **新增** `src/runtime/audio.{h,cpp}`：`AudioEngine`（设备模型 / 逐缓冲 44.1k mono 与 48k stereo /
  线性重采样到 48k / 混音 / SDL3 / WAV dump / 通知队列 / feeder 状态机 / 整份 guest 上下文交换）。
- **新增** `src/runtime/sync_guest.h`：以指定 guest 线程身份 Enter/Leave/查 CS（布局仍只在
  `kernel32_sync.cpp` 一份）。
- `src/shims/dsound.cpp`：`QI(Notify)` 建带 owner 的状态块；`SetNotificationPositions` 真存；
  `Play/Stop/SetCurrentPosition/SetVolume/SetPan/Unlock/GetCurrentPosition/Release` 驱动/查询设备；
  `WAVEFORMATEX` 逐缓冲交给引擎。
- `src/shims/kernel32_sync.cpp`：`CreateThread` 识别 `0x4B5AA0` 登记泵；`ResumeThread` 置 runnable；
  `SetEvent` 识别退出事件；`WaitForSingleObject(feeder)` join（防 UAF）。
- `src/runtime/machine.{h,cpp}`：`configureAudio` / `audio()`；块边界 `audio_.pump()`；
  嵌套 guest 调用期间不 pump 窗口/定时器；续延后 `afterGuestCall()` 还 `[esp]`。
- `src/main.cpp`：`--audio off|sdl|virtual`（默认 `sdl`）、`--audio-dump <wav>`。

## 验收（机械 + 实跑）

- `ctest -R audio-device`：48k stereo 通知次序 0,1,2,3,回绕 0；dump 前 0.5 s 与 guest 斜坡逐字节相同；
  44.1k mono 重采样 L==R；feeder register/resume/quit/join；fake `sub_4B6C30` 改掉全部 GPR/x87/XMM
  后逐字段复原；CS / 在飞计数成对收尾；`[esp]` 还原。
- 全量 CTest：**59/59 passed**。
- 实时实跑（RelWithDebInfo，`--skip-logo --native-overrides all --real-time --audio sdl`，
  HUAWEI USB-C HEADSET）：20 s 内 `fills=30 / notify=30 / underruns=0`；fill 墙钟 344–425 ms；
  dump 5–19 s 连续、RMS 4.3k–6.0k、无 2 s 周期。BGM 在 TITLE 真的出声。
- 偏差 / 未做：61 个 guest 通知事件不 SetEvent；join 直接置 exited；SE 延迟 ≈ lead 600 ms；
  不真并行；重采样线性；fill 吞吐是 D 的硬约束。详见报告。
