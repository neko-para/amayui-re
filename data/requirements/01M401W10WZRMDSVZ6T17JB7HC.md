## 背景
译文真源 = `data/translations/patch.json`。核对手法 = 把它摊成可检索视图后实测：

```bash
pnpm tools patch view --kind src            # → dist/views/src/<脚本>.BIN.txt
rg -n --no-ignore '<字串>' dist/views/src   # 只在**译文位置**计数，别把 comment "日文" 算进来
```

★ **两条口径**（都是实测踩出来的，写在这里免得下一个人再踩）：

1. **`comment "…"` 里的是日文原文标记，不是译文** —— 不排除它会把判断完全带偏
   （实测：`嵐燐` 13 处命中里 13 处是 comment，只有 1 处是真的）。
2. **`display-furigana "A" "B"` 是「主词 + 注音」，B 不是竞争译名** ——
   实测 `精域神战争` / `菲优希亚圣战` 就是这一对，而且 SC2770 自己写着
   「后世称之为『精域神战争』或『菲优希亚圣战』」⇒ **两者都合法，不是冲突**。

旧仓翻译文档（现为只读快照 `docs/01-translation/ref/`）里声明的「同名多译」**大部分已闭环**
（尤艾拉 · 魔械 · 哥雷姆 · 贝利亚尔 · 子种 · 遮布 · 菲亚小姐 · 罗兹莉奴 · 伊奥尔 · 米库舒安娜 ·
菲娅 · 本姑娘 · 法斯蒂纳 · 吉那泰由 · 卡托利特 · 帕拉伊亚/帕莱亚 · 云驱/腾云吊桥 · 爱娇 ·
魔封炼匠 · 华燐（只在 comment 里） … 实测译文位置 0 命中）。

## 判据
逐条收敛：**同一对象只留一种写法**。若判定「两者是不同对象 / 都合法」，把结论写进本条正文并勾掉该项。
全部勾掉后按 `done_reason` 收口 —— 无守卫可挂：断言「某字串不存在」属**数据当前取值**，不进测试
（`AGENTS.md` §10「测试只测基建契约」）。

判「是否同一对象」的最省力办法：**`data` 视图与 `src` 视图同构**（同文件、同行号），
拿 `dist/views/data/<脚本>.BIN.txt` 的**同一行**看日文原文即可 —— 日文词不同就不是一回事。
