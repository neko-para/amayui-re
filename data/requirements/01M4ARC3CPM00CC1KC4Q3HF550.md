# ADR · 模拟器要有统一地址空间（扁平 + 合成 + 稀疏）：指针族与容器句柄的存储基础

- id: REQ-01M4ARC3CPM00CC1KC4Q3HF550
- type: decision
- status: done
- done_reason: 已裁决：要有统一地址空间（扁平+合成+稀疏）。可执行形式 = apps/emulator/src/model/address-space.ts（11 条守卫 + 进分区表 + 3 条变异条目）；设计记录 = docs/03-emulator/address-space.md；执行计划 = M4-1b 的迁移三步。decision ⇒ 不可变，推翻需新增一条并 supersedes。

## 决策

**模拟器里要有统一地址空间**（扁平 + 合成 + 稀疏）。依据是用户口径：

> 这个模拟器预期应该能像真正的引擎一样驱动游戏，因此只要确实涉及到的能力都是要支持的。

⇒ **不允许**留"永久不支持"：某一项暂时不实现，只能是**已登记的、会收口的**节点。

## 为什么（指针表达不出来）

取证逐字形态（锚 = EA，见 `data/ledger/`）：`global-ptr` 读 = `池基址 → 取第 idx 格（一个地址）→ 解引用`；
`create-mesh` 的顶点数组 = `操作数解出的地址 + 4*i`。⇒ "值在 `[地址]` 里"要求模型里**存在地址**。

## 形状与被否掉的替代

* ✅ **扁平**：`地址 = base + elemBytes*index`。引擎的 `base + 4*i`、`lea`、指针加减原样成立（它们本来就是地址算术）。
* ✅ **合成**：地址由本层发（`ORIGIN` 起 bump），**不是**宿主真地址 —— 真地址会让两次运行不可比、快照不可 diff、日志不可 diff。
* ✅ **稀疏**：格子按需出现；池的容量至今没有逐字取证 ⇒ 现在就能建、能寻址、能解引用，不必先编一个容量。
* ❌ **结构化指针**（`{池名, 下标}`）：脚本一旦对地址做算术（取结构体中间某字段的地址），"哪个池的第几格"没有唯一答案 ⇒ 要么失败要么猜。
* ❌ **继续不支持**：与用户口径直接冲突。

## 不变量（每条都有守卫：`tools/test/emulator-address-space.test.mjs`）

1. 同一分配序列 ⇒ 同一批基址（不依赖宿主/时刻）。
2. `addressOf(i) → resolve` 回到同一格；区域末地址之后不是本区域。
3. 解引用链成立；不解除引用会得到地址本身（类型对、值错）。
4. 三种失败分得开：`unmapped` / `misaligned` ⇒ 抛（带地址）；`unwritten` ⇒ `null`（**不是 0**）。
   引擎越界时没有边界检查（安静读到相邻内存）= UB，本层不模仿。
5. 快照：同状态 ⇒ 逐值相同；恢复后**不许重发**已用过的地址（重发 = 两块数据别名）。
6. 本层只管字节：不认 DEC/ENC、不认 SSO、不认容器（取址原语确实不解码）。

## 它逼出来的三件事（都登记在需求树）

1. **区域容量从哪来** ⇒ 必须解决"头部 6 个 `local_*` 字段 → 6 个池"的**对应顺序**
   （`LOCAL_POOL_SLOTS` 的池序 int/float/string/ptr/floatPtr/stringPtr vs 头字段序）。
   ★ 采用地址空间把这条"未取证"从"可以绕开"变成"必须解决"。
2. **`*_alt` 池（memflip）** = 同一批数据的两个区域（六对交换，开关 `set:EnableMemFlip`）；本层能表达，何时交换未取证。
3. **容器句柄 `0x800x`** 要懒分配 + 登记（`Engine+0x5D860/0x5D870`、`帧+0x5D904/0x5D908`）；本层给存储与地址。

## 迁移计划（本批只立接缝，不动池）

现状：池层存储 `Map<池名, Map<下标, 值>>` 与地址空间里的字节是**两份**。目标是**一份**。
① 本批：地址空间独立可测 + 进分区表 + 变异条目；② 池存储换成区域（判据 = 既有守卫全绿 +
"经地址空间读到的池值 == 经池 API 读到的值"）；③ 指针族与 `0x800x` 接上，删掉 `unimplementedPointerType`。
★ 迁移**不改语义层的外部形状**：`read/write/snapshot/restore` 一个都不变，换的只是"值存在哪"。

## 同一轮的另一个决定（随机源）

`0x60 random` 语料 22 处 ⇒ 必须支持。做法：随机源**注入**（`src/host/random.ts`），
种子由前端给（`--rng-seed` / `AMAYUI_RNG_SEED`，默认是**显式常量**而不是时刻）；
没有源时该指令**响亮失败**（不许退回 `Math.random()`）；每次取数发一条 `system.random.draw`
（取数次数本身是复现性判据）。★ 未实现并显式登记：体内那个上限 12 的重掷计数器（`Engine+0x69330`，
"何时重掷"未取证 —— 猜出来的重试会让取数次数错）。
