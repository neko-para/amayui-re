# emulator-lift · 声明路的 DrawIndexedPrimitive 区间映射没有守卫（+ start_index 回绕）

## 缺口（D3D9 #5 复审的"可另开单"）

`d3d9p/indexed-range` 的四条用例只走 **FVF 路**；声明路（`kPlVertexDecl`，Live2D 用）的 `first = base + min` / `relative = idx - min` 映射**没有守卫**。
另：`start_index + index_count` 的 u32 回绕是既有问题（本轮没动）。

## 判据

- 声明路加一条用例（`d3d9p/indexed-range-decl`）：与 #5 的 (a)(b)(c) 同形，走 `IDirect3DVertexDeclaration9` + 两条 stream ⇒ 像素/拒绝码与 FVF 路一致。
- `start_index + index_count` 用 int64 判定，越界 ⇒ `D3DERR_INVALIDCALL`（不依赖 u32 回绕）；加一条边界用例。
- 变异：把声明路的 `relative` 改回 `idx`（不减 min）⇒ 用例红。

## 非目标

- 不改 FVF 路既有四条；不扩多 stream 语义。
