## 已落（2026-11-02）

- **`0x220`**：标题改成「平移 + 平移窗 + 标志」；状态表从「两个整数属性」改成「平移窗延迟 / 持续时间」；正文写明 `G0` = 窗起点（与 `0x202` 同格）、`G1` = 延迟、`G2` = 持续时间、`G3` = 重算标志；三档判据同「场景计时窗」；**持续时间 ≤ 0 只跳过推进**（排窗仍写矩阵 / 标脏）。删 `RES-SCENE3D-XFORM-INTFIELDS`；新增 `RES-SCENE3D-XFORM-WINDOW-VALUES`（插值起值 / 终值未读）。

- **`0x32a` / `0x329`**：`0x32a` 的对象改成「**网格槽表**（与 `0x32b` 同一张 1000 槽表）」，创建者 `0x329`；槽范围写清「本版只规定 0..2；容量 1000；3..999 表内未规定；0..999 之外才是 UB」；`RES-SCENE-EFFECT-OBJECT` 收窄到「对象类型未定」，`0x329` 的建对象语义进 `GAP-OPS-0300-03FF` 的 `RES-GAP-329-MESH-OBJECT`。
- **`0x203` 顺带**：该格随 740 字节记录整块进存档；`RES-SCENE-UNKNOWN30` 收窄到「直接遍历结点 / 平台资源接口」。
