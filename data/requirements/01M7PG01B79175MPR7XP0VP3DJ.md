## 现象

加载 `saves/SAVE04.DAT`（第 5 槽）→ 进地图 →「要接受迷宫教程吗？」选**不接受** → 进地图的
blind wipe / blur 转场里 `exit 3` + `=== guest memory fault ===`：
`WRITE 0x1005BA8C size=4` · `region(ea): heap` · `why: SIGSEGV @ host 0x300000020`。

## 复现（2026-11-18 / macOS arm64 / 1/1）

交互式 emu-ctl 读数见 `docs/03-emulator/defects.md#BUG-32`；**一次性配方已通过**：

```bash
cd apps/emulator-lift
./out/emulator-lift-aot --present headless --skip-logo --audio off \
  --game-dir ../../links/install --appdata <私有副本> \
  --input-plan scripts/recipes/save04-fault.plan --max-frames 4000 --time-limit 300
```

⇒ exit 3；fault 现场 `eip=004A50C0` / `lift_cc_004A50C0` / `ebx=00000024` /
32 字栈 + ebp 链；`input-plan: steps=38 fired=10 pending=7 outcome=running`（`pending=7` 是 `_Exit(3)`
的正常形状）。存档 sha256 `e8a6dbf3…`；崩溃前 sample `SC4000.BIN:0x00010D88` frame 1232；
崩溃帧 1264 先建 `D3DXCreateEffectFromResourceA id=201/203` 后 fault。

## 未定（⛔ 不猜根因）

- `eip=004A50C0` 与 `0x1005BA8C` 的写者 / 对象尚未定位；没有跑「选是」对照；win 侧未比对。
- 旧 `.tmp` 配方卡 SC0000 的前提**已被推翻**：click 被消费，卡点是门的坐标（`0x5900` 只有点了才到；
  正确门 `[0x5800,0x5860)`）。`releaseDue` / `sampled` 不是根因，release 语义未改。
