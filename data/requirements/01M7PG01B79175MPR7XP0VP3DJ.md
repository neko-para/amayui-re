blind wipe / blur 转场里 `exit 3` + `=== guest memory fault ===`：
`WRITE 0x1005BA8C size=4` · `region(ea): heap` · `why: SIGSEGV @ host 0x300000020`。

## 复现（2026-11-18 / macOS arm64 / 1/1）

交互式 emu-ctl 步骤与读数见 `docs/03-emulator/defects.md#BUG-32`，完整报告在
`.tmp/save04-tutorial/report.md`。存档 sha256 `e8a6dbf3…`；崩溃前 sample
`SC4000.BIN:0x00010D88` frame 1232；崩溃帧 1264 先建 `D3DXCreateEffectFromResourceA id=201/203` 后 fault。

## 未定（⛔ 不猜根因）

- fault 时没有 EIP / 寄存器 / 栈（AOT 臂没有 `Machine` ⇒ `liftFaultHook` 未装）。
- 没有跑「选是」对照；win 侧未比对；`0x1005BA8C` 的写者未定位。
- `.tmp/save04-tutorial/save04-tutorial-no.plan` 未通过：卡在 SC0000 首句（`--input-plan` 的 click 不被消费，
  同坐标 emu-ctl 可推进）⇒ 不能把配方当复现件。
