## 目标

把 **`T0`（obj0）的"观察了但没声明"** 变成一张**按站点数排序的可执行清单**，并逐批补齐：
每个补上的成员都必须有 witness EA、且补完五个模型仍全绿。

## 为什么要单独立单（这是当前最大的一块欠账）

类型表 `complete: false` ⇒ 未声明的偏移**不红**（只进残差 / 不判定）。于是"没声明"与"没有"在报告里长得一样。
实测（handler 子集口径，`pnpm tools shape census` + 与 `data/shape/types.json` 做差）：

| | 偏移数 | 站点数 |
|---|---|---|
| 已声明 / 落在帧数组窗口内 | 66 | 1902 |
| **未声明** | **238** | **1197** |
| 其中"对象头部区"（`< 0x3064`） | 18 | 236 |

⇒ **约 39% 的 obj0 站点目前落在"没声明所以不判"里**。这不是错，但它是"覆盖率"的真实读数，
也是"下一轮该做什么"的唯一诚实来源。

## 已完成的第一批（10 个偏移 / 17 处残差清零）

判据：17 处 `⚪` 逐条 `--verify` 过（全是 `lea <reg>,[esi+imm]`，`access=a`、`stride=0`、`indexSym=null`），
成员只写 `{off, width:4}`（`evidence` 不进产物）。合并后控制流族 **守恒① `197 = 解释 197 + 残差 0`**。

## 判据（后续批次）

* 每批（按站点数降序，一次 5~10 个偏移）：
  1. 每个偏移给 **witness EA**（`--census` 的 `sampleEAs` + `--access` 的逐站点）与**宽度**（`w=`）；
  2. 补进 `data/shape/types.json` 的 `T0`（`complete` 保持 `false`）；⛔ 不许凭印象补、不许为清零而编；
  3. 补完跑：`claims` 五个模型全 exit 0 · `--sample` exit 0 · `mutate check --match shape` 13/13；
  4. 记 **守恒③ 各桶前后对照**（残差应下降，且没有新桶出现）。
* ★ **只出现 1 次也照收**（有 witness 就是观察），但要与"对象头部区"（`< 0x3064`，18 个偏移 / 236 处站点）**分批**。
* ★ 前缀相关的偏移优先（如 `0x5c73c` / `0x5ec7c` / `0x7795c` 一族）：补一个能带一串站点被判定。

## 三类"不是欠账"（别当覆盖率）

1. **数据段符号**（`ds:` 前缀，无基址寄存器）⇒ 形状层表达不了（单列桶，⛔ 不是通过）；
2. **分支合并后的未解析基址**（实测 `sub_41C6A0`：`add esi,8` 只在抛异常分支上，汇合点两条路不同
   ⇒ 助手判 UNK 是**正确**的；我一度以为是 bug，打补丁实测 **0 变化**，补丁作废）；
3. **跨两级以上的指针链** ⇒ 不判，用**局部类型载体**表达；
   其中"层级 3 的指针只在 caller-saved 寄存器、活窗口被 `call` 打断"的那一小撮**结构性判不了**
   （实测 `0x42165f` / `0x42189f`），必须留在这档。
