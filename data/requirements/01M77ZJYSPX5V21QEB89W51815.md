## 现象
`graphs/sn0000-save.graph`（TITLE → GAMESTART → SN0000 → 右键 → FELLOW → SAVE → 选项存档）在**写存档**时命中：

```
stop      : unimplemented-slot @ eip=004A0572
detail    : unimplemented COM vtable slot（shim com!IDirect3DDevice9::unsupported+0x90）
```

用户实测 2026-11-12。此时 `SAVE00.DAT` 已被 `CreateFile` 建成 **0 字节**，存档流程中断。

## 复现
```bash
cd apps/emulator-lift
./out/emulator-lift --present window --present-hidden --raster gpu --native-overrides all \
  --skip-logo --audio off --game-dir ../../links/install --appdata <tmp> \
  --interaction-graph ../../graphs/sn0000-save.graph --max-frames 6000 --time-limit 300
```

## 根因（`.lst` + 运行期栈）
存档缩略图链 `sub_4A0430`（GetTextureSurface）在拿到源 surface 的 `D3DSURFACE_DESC` 后调用：

1. `CreateOffscreenPlainSurface`（`IDirect3DDevice9` **+0x90**，调用点 `0x4A0570`）——
   参数 `(desc.Width, desc.Height, desc.Format, D3DPOOL_SYSTEMMEM=2, &ppSurface, NULL)`；
2. `GetRenderTargetData`（**+0x80**，调用点 `0x4A05D2`）—— 源纹理 RT → 新建的离屏表面；
3. 调用方 `LockRect` 读像素；随后 `UpdateSurface`（**+0x78**，调用点 `0x4A479D`）把 320×180
   缩略图写回纹理表面。

本线此前三槽**都没实现**：+0x90 先撞上（用户看到的那条），修掉后 +0x78 接着撞。

## 修复
- `CreateOffscreenPlainSurface`：用现有纹理状态块 + arena 像素块建**无父对象**的
  `IDirect3DSurface9`（`createD3dxSurfaceObject` 新增 `on_zero` 钩子，refcount 到 0 时回收
  状态块 + 像素块）；`pSharedHandle != 0` ⇒ `D3DERR_INVALIDCALL`。
- `GetRenderTargetData`：校验两表面尺寸/格式一致（不同 ⇒ `D3DERR_INVALIDCALL`），源是当前 GPU
  镜像目标时先 flush+读回（与 `LockRect` 同一屏障），按 pitch 逐行复制，目标内容版本降级为未知。
- `UpdateSurface`：源矩形 → 目标点的原样复制（无缩放/格式转换），同样的 GPU 屏障与越界拒绝。
- 纯档守卫：`apps/emulator-lift/tests/d3d9.cpp` 的 `d3d9/offscreen-surface-rt-data`
  （建 64×32 RT 纹理 → Clear → 建离屏表面 → GetRenderTargetData → LockRect 逐像素；
  UpdateSurface 全幅/子矩形/越界；尺寸/格式/非 surface/共享句柄的失败面）。
- assets 档守卫：`apps/emulator-lift/tests/save_graph.cpp#save-graph`（真窗口 + GPU 跑整张图，
  断言 `task done`、无 unimplemented、`SAVE00.DAT` ~1 MB 与 `SAVE00.STH` 缩略图真的落盘）。

## 判据
- 同 graph 复跑不再出现 `unimplemented-slot`；`detail` = `interaction: task done`；
- `SAVE00.DAT` / `SAVE00.STH` 非空（实测 1,048,521 B / 172,854 B）。

## 备注
- 图的最后一段原来只有 `wait 5000 wall_ms`：模拟器上存档（缩略图 + 1 MB DAT）要 ~7 s，
  图先结束 ⇒ 文件停在 0 字节（**不是**判据红）。已把最后一段拆成 5×`wait 5000 wall_ms`（25 s 收口）。
- `$$AGE.TMP`（恢复标记）在 run 被宿主停下时会留下 0 字节残留；这是既有语义，不影响存档文件。
