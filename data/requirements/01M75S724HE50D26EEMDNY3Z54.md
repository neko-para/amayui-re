# 错误被折叠成成功/看不见：ExitProcess(n) 丢 n · MessageBox 正文默认不可见 · LZSS override 静默截断

- parent: REQ-01M6H6G6DSRG1ZRD810Z0HTH8V

## 一句话

emulator 有**三处**把"失败"折叠成"成功/看不见"，其中任何一处都会让"引擎走了错误分支"变成**不可观测**：
进程以 0 退出、弹框正文默认不打印、解压失败仍报成功。这是**诊断能力**的缺陷，不是 LoadData 的根因 ——
但它让任何"引擎自己退出"的现象都长得像正常收尾。

## 三处（父级已逐条读源码确认）

### 1. `ExitProcess(n)` 的 `n` 被丢弃 ⇒ 一切非 0 退出伪装成 0

- `n` 只进 `cpu.shim.exit_code`（`x86.h:152`），**从不参与进程退出码**；
  `main.cpp:1319` → `machine.cpp:79` 只看 `ok()`（`ok() ? 0 : 2`）。
- ⇒ 引擎 `exit(3)` / `abort` / "致命错误后 ExitProcess(1)" 与"正常收尾"在**退出码上完全同形**，
  差别只在一条 **Info** 日志的 `exit_code=`。
- **修**：`ExitProcess(n)` 且 `n != 0` ⇒ 进程退出码非 0（与 decode-error 同档，建议 2），`n` 进日志；
  `n == 0` 保持 0。⛔ 不要把 guest 的任意 `n` 直接当宿主退出码（会被 shell 截断/误解）。

### 2. `MessageBoxA` 的正文默认不可见（返回值恒定）

- `src/shims/user32_menu.cpp:179-203`：`call.result = 1` 恒 IDOK、**不看 `uType`**、不建窗口不阻塞。
  ⇒ 引擎的 `==IDCANCEL` / `!=IDOK` / `==IDNO` / `==IDABORT` 错误收尾分支**恒不成立**；
  而正文（引擎自己的错误串）只进 **Info** 日志 ⇒ 默认 `warn` 级**看不见**，于是"没弹窗"在 emulator 里不可观测。
- 文件自己的注释写着"必须进日志（2026-11-05 用户口径）"，但级别让它默认不可见 ⇒ 注释与实现不符。
- **修**：正文的 `shimLog` 升到 **warn**（错误串必须默认可见）；返回值语义**另裁**（见下"未做"）。

### 3. LZSS native override 静默截断却报成功

- `src/runtime/native_lzss.cpp:30-56`：解码循环里三处 `in >= in_end` ⇒ `break`，然后**无条件 `return true`**
  —— **既不检查 `in == in_end`，也不检查 `out == out_end`**。压缩流被截断（或 `comp_size` 给错）时，
  输出只填了一部分，调用方拿到的却是"成功"。
- 只走 `--native-overrides all`（用户测试的常规口径）⇒ **正常游玩就是这条路径**。
- **修**：`break` 后必须区分三类结尾 —— 正常结束（`out == out_end`）⇒ true；输入提前耗尽/输出没填满 ⇒ **false**，
  并让调用方走"这个 override 不适用 ⇒ 回退解释器"（⛔ 不要用"输出缓冲区剩余部分填 0 再返回 true"糊过去）。

## 判据（红了意味着什么）

- ① 一条用例：guest 调 `ExitProcess(3)` ⇒ **进程退出码 ≠ 0**；`ExitProcess(0)` ⇒ 0。
- ② 默认日志级别（`warn`）下，`MessageBoxA` 的 `text=` 必须出现在输出里。
- ③ 一条用例：给 `nativeLzssDecode` 喂**被截断的**压缩流 ⇒ 必须返回 false；喂合法流 ⇒ true 且输出逐字节正确
  （后者的期望值用**解释器臂**算，⛔ 不手写参考实现）。

## 未做 / 需另裁

- `MessageBoxA` 的**返回值语义**（2026-11-12 已裁决）：按 `uType&0x0F` 给合法值；`MB_YESNO` 默认与 X/Esc = **IDNO(7)**；
  窗口档为宿主自绘模态对话框，headless/feeder 立即默认值 + warn。
- `FindFirstFile` 在目录不存在时给 `ERROR_FILE_NOT_FOUND(2)` 而非 `ERROR_PATH_NOT_FOUND(3)`
  （`kernel32_file.cpp:2097` + `vfs.cpp:705-727`）、`GetSystemMetrics` 未建模恒 0、菜单/AGERC 族恒 0/NULL、
  路径失败降成 Debug：同属"折叠"但**各有独立后果**，需要时单独开单，不塞进本单。
