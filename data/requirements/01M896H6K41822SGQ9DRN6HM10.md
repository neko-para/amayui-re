# 设置模块：插件声明设置项 + 二级设置页（实时生效）— 已交付

## 已交付（2026-11-25）
- **注册**：`scripts/plugins/lib/settings.js` 的 `registerSettings(ctx, spec)` 把
  `{title, live, entries}` 写进**保留配置域 `settings.schema`**（key = 插件域 id）；
  写前 `all()` 比对、相同不写；任何失败只 `log warn`，⛔ 不打死 Run。
- **页面**：`scripts/ui/settings-page.js`（`PAGE_KEYS` / `canOpen` / `hasSettings` / `drawPage`）——
  全屏背板 `settings.bg`（模态）+ 页板；bool = 整行热区 `set:<domain>:<key>`（右端 20×20 方框），
  number = `dec:/inc:` 24×24 + 值文本 + min/max clamp；`BACK` 112×28；无滚动、最多 12 行。
- **入口**：HUD 面板最后一行 `settings…` + 透明命中 Rect（`key:"settings"`）；HUD 的
  `host.config` 是**唯一** config 渲染面（`--overlay --plugin <无 render 插件>` 与 run 插件同进程，
  同一份 `PluginConfig`）⇒ 页面新鲜、改值下一拍生效；预设 `--overlay` 没有 config ⇒ 只显示
  `settings: 没有注册设置` / `没有 appdata`。
- **实时**：页面每帧 `get`；消费者在**自己的读点**重读（`field` 的 `on/poll/diag` 每拍重读）。
  ⛔ 不引入观察/通知机制；`live: frame|run|restart` 只是插件自报。
- **落盘**：`present_sdl` 每帧 render 之后**无条件** flush（render 抛错那帧也 flush），
  `disableOverlay` / `shutdown` / `releaseOverlayConfig` 各一次。
