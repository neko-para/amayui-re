# emulator-lift · overlay PROFILE 按钮：点击定界区间 profile，结束写剪贴板

## 目标 / 用户面

overlay 上提供一个 **PROFILE** 按钮：第一次点击开始一段区间 profile，再次点击结束；结束时把**结论文本**写入系统剪贴板，并在 HUD 上给一行状态（开始 / 已复制 / 失败 / INVALID）。

## 现状（2026-11-18 评估，只读）

- **profiler**：AOT 有 `AotWindowProf`（`src/aot/window_prof.h:52`），**不是**解释器的 `WindowProfiler`；`AotHost::beginWindow(label)` / `endWindow()`（`aot_host.cpp:1236/1279`）已是全部接口，`endWindow` 直接 `printf` 到 stdout。配方 `profile_begin/end` 走同一对函数（`input_plan` → `windowMarkThunk`）。
- **overlay**：`UiBuilder` 只有 Rect / Text，`Element` 无 `interactive`；`SdlWindow::handleEvent`（`present_sdl.cpp:556`）把四类鼠标事件**无条件**转给 guest，没有命中测试；`mapMouse` 是 window→guest image（带 clamp），不能复用到 overlay。
- **剪贴板**：全仓零实现；宿主 SDL3 有 `SDL_SetClipboardText`（UTF-8、bool、主线程），**不需要** user32 shim（overlay 是宿主 UI）。
- **文档不一致**：`input_plan.h:41` 的「本臂没有区间 profiler」是旧口径（AOT 2026-11-17 已有；blame 见 `.tmp/overlay-profile/profiler.md` §3）。

## 设计（已评估，待实施）

1. **报告文本化（先做，可独立测）**：把 `endWindow()` 的打印体抽成 `formatWindowReportText(const AotWindowProf&, ShimNameFn, top=8)`，放 `src/aot/window_prof.cpp`（runtime lib，pure 可测）；`endWindow` 改为 `fputs` ⇒ stdout 逐字不变。文本 ≤20 行：label / wall / iter / sampled / insns / frames、lift / boundary / shim / instrument / unaccounted / coverage、Top-8 shim + `(rest)`、verdict、lift_dyn。⛔ 不含 `.lst` 函数名（AOT 拿不到，只有 `module!name`）。
2. **宿主桥**：`AotHost` 增 `endWindowText(std::string*)` 与 `profileOpen()`；`beginWindow` 在**已开**时返回 false（⛔ 不再静默 `reset()` 冲掉在开窗口）；未闭合在 run 收口打一行 warn。profile 归 `AotHost` 所有，overlay 只发请求。
3. **overlay 命中**：`Element` 加 `std::string key` + `bool interactive`；JS 加 `ui.button({key,x,y,w,h,label,...})`（画 Rect + Text 并登记）；宿主按**上一帧成功 present** 的 resolved rect 逆绘制序命中；不另存 hit 数组、不 clamp 到画布（黑边点击不应命中边缘按钮）。
4. **事件边界**：左键 down 命中 ⇒ 吞 + capture；up 无条件吞，抬起点在同一 key 的 rect 内才发 click；motion / wheel / 右键放行；拖出取消；关闭 / 失焦 / 新 down 清 capture。⛔ **不在 `handleEvent` 里跑 JS / 开 profile / 写剪贴板**（它可能在 guest `GetMessageA` shim 内）——只记 pending，下一帧由脚本消费。
5. **JS API**：`game.click` 一次性 `{key,x,y}`（ref 坐标）；`game.profile_open` 只读；`host.profileBegin(label)` / `host.profileEnd()`（返回 `{ok, text, error}`）；`host.copy(text)` 可选。按钮的 `idle/profiling/done` 状态归脚本；结束时宿主格式化 + `SDL_SetClipboardText` + 一行 stderr；失败 HUD 行 + 一次性 stderr。
6. **碰撞 / 边界**：配方已开窗时按钮显示 busy、点击 no-op（⛔ 不 reset）；`sampled==0` / `unaccounted` 超限 ⇒ 文本保留 `INVALID`，仍复制并 HUD 警告；双击按 `game.profile_open` 判状态，不会重复开窗。
7. **平台**：macOS 高密度屏要确认 `presentGeometry`（像素）与 SDL 鼠标事件（点）的 ratio；headless 下 `--overlay` 已被拒；`--present auto` 隐藏回退可复制但**不可点击**。

## 切片

1. 报告文本化 + `aot-window-report-text`（pure）+ `aot-window-state`（double begin / cancel / unclosed）。
2. UI `key/interactive` + `ui.button` + 命中/捕获（pure `ui-hit` / `ui-click-router`）+ `present-window` 的 `SDL_PushEvent` e2e。
3. 接线：`AotHost` 桥 + `game.click` / `host.profile*` + `SDL_SetClipboardText` + HUD 状态。
4. e2e：点击 overlay 不穿透 guest；剪贴板 roundtrip（失败 SKIP 77，⛔ 不进默认档）。
