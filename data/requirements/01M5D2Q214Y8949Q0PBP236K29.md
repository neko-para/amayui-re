# spec 的 storage 指针应指向 shape（data/shape）而不是 age-format 的 layout.mts：60 处 layout: 分批迁出 + 棘轮

## 问题

`bindings.storage` 现在**以 `layout:` 为主**（60 处）而 `shape:` 只有 6 处：

```
layout: 60    shape: 6（全部是 texture/scene 的 T_Scene_* ）
```

`layout:` 指向 `packages/age-format/src/engine/layout.mts` —— **age-format 是历史知识产物**，规范**不允许**依赖它。机器本体应当由 **shape 层**（`data/shape/`：`carriers.json` 的槽 + `types.json` 的类型）提供，`storage` 指针应写 `shape:<类型名>`。

**现状卡点**：`data/shape/types.json` 里**没有任何帧类型**（全文 0 处 "Frame"）⇒ 帧相关规则（`CORE-FRAME-STACK` 等）目前**无法**写 `shape:` 指针。

⇒ 已知的债：**规范的可复核材料目前仍吊在 age-format 上**；与"spec 不依赖 age-format"直接冲突。本单拆掉它。

## 分阶段（每阶段独立可验收）

| 阶段 | 动作 | 判据 |
|---|---|---|
| S1 | 在 shape 建**帧记录**类型与载体（`data/shape/types.json` + `carriers.json`；身份用 EA / 地址表达式，⛔ 不用助记符/行号） | `pnpm tools shape claims --sample` 通过（G1 重叠 / G2 覆盖 / G3 步长 / G4 边界） |
| S2 | 把 `CORE-FRAME-STACK` 的 `storage` 从 `layout:FRAME_LAYOUT.*` 换成 `shape:T_Frame*`；若帧字段仍缺类型，**分字段迁**（先迁 `count`/`cur` 两格的载体） | `pnpm tools spec validate` #6 通过（`shape:` 形态已被 resolver 支持：`/^shape:[A-Za-z_][A-Za-z0-9_.]*$/`） |
| S3 | 按机制分批迁其余 `layout:`：pools（`GLOBAL_SLOTS`/`LOCAL_POOL_SLOTS`）、engine-state（`ENGINE_SCALAR_*`）、pools 容量 | 每批：`spec validate` 绿 + `layout:` 计数**单调下降** |
| S4 | 加**棘轮守卫**：`layout:` 指针总数只许下降（防止新规则再挂回 age-format） | 新守卫（会红）+ `tools/mutate-check.mjs` 一条变异 |

## 不许做

- ⛔ 为了让指针"能解析"而在 shape 里编类型名/编偏移（shape 只收**可再校验的载体观察**）。
- ⛔ 一次全量替换（60 处）—— 按机制分批，每批跑 `shape claims` 与 `spec validate`。
- ⛔ 把 `layout.mts` 当成"第二真源"继续引用；它最终应废弃（与 `age-format` 一起）。

## 完成判据（本单 done）

- `bindings.json` 里 **`layout:` 指针 = 0**（或只剩显式登记的、无法由 shape 表达的例外，并在 `audit` 里逐条给理由）；
- 四道门禁 + `shape claims --sample` 全绿；
- 棘轮守卫在位（新规则若挂 `layout:` 当场红）。
## 订正（2026-10-21，用户指出）

**帧记录的类型在 shape 里已经存在**：`data/shape/types.json` 的 **`T1`** —— `size = 120 = 0x78`（与帧记录步长一致），28 个成员，含 `0x38`（父帧号）、`0x3c`（统一文件 id）、`0x60`（操作数个数槽），与 `FRAME_LAYOUT` 的偏移逐项对得上。名字叫 `T1` 只是因为**没有 RTTI**，不是"没有类型"。

⇒ 据此修正计划：

- **S1 不再"建类型"**：改为 **确认 / 补登记载体**（帧区 = `obj0 + 0x5D894` 起、40 个 `T1`、当前帧号那格）；`carriers.json` 目前只有 `b14x-t1` 与 0x5D800 游标块的记录，数组本体要核。
- **S2 用 `shape:T1`**（不是新造 `T_Frame`）：⛔ **不要改名** —— shape 的名字只是身份，改名等于往机器层注入语义；"`T1` = 帧记录"这条**映射说明**放在 bindings/本单，不放进 shape。
- 其余（S3/S4 与判据）不变。
