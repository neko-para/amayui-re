# Windows 真机字形来源：`EMULATOR_CXX_GLYPH_GDI=1`（GDI `GetGlyphOutline`）

## 判据

- 开 `EMULATOR_CXX_GLYPH_GDI=1` 后，`0x204` 的字形必须**真的**来自 GDI：`last_glyph_source() == Gdi`、
  有墨迹，且格式按引擎的 AA 配置（无 AA 配置 ⇒ 1-bit，alpha 只含 0/255）。
- AA 档：把 `set:EnableAntiFont` + `message:UseAntiFont` 打开（`message:AntiFontLevel = 0` ⇒ GRAY4）后，
  合成的 alpha 必须**全是 15 的倍数**（引擎 ÷17 的必要条件）、有中间值、峰值 ≥ 200
  （实测 15,30,…,240 —— GDI 的 GRAY4 原始值是 0..16）。
- 守卫：`core_selftest` 的「`0x204` GDI 字形来源没生效」与「`0x204` GDI 的 GRAY4 档不对」。
  变异（手工、撤销）：`gdi_glyphs_enabled()` 恒 false ⇒ 红（`source=1`）；÷17 改"原始值直接当 alpha" ⇒ 红
  （`max_alpha=16`）；÷17 改 ÷16 ⇒ 红（31/47 不是 15 的倍数）。
- 不设 env 时行为**不变**（FreeType 回退）；非 Windows 上没有实体、自动回退。

## 判据之外的口径

- 这是**真机路径**，不是"又一个渲染后端"：引擎本来就把字形请求交给平台
  （`0x46F5BC` / `0x471723` = 长度 / 本体两次请求，`fuFormat` 由 `Font+0x548` 决定）。
- 取字参数：`lfHeight = −字号`、`lfWeight = 0x2bd` 那一格、`lfFaceName = 0x1a5 写的字面名`
  （本机实测是「ＭＳ ゴシック」/「ＭＳ 明朝」）、`lfQuality = DEFAULT_QUALITY`（引擎 lfQuality 恒 0）。
- 落点：`repo:apps/emulator-cxx/src/core/text_gdi.cpp`；取证：`repo:docs/02-engine/ops-forensics-2026-10-title-option.md` §41。
