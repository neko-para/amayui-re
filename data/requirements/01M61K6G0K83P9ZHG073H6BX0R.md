# 配置根读成漫游 %APPDATA%（应为本地 %LOCALAPPDATA%）：玩家层整份没被读到

- id: REQ-01M61K6G0K83P9ZHG073H6BX0R
- type: bug
- status: done
- parent: REQ-01M5Z5D786WF65YWHFK7K8Z7Q8
- repro: apps/emulator-cxx/CMakeLists.txt#emulator-core-config-root
- severity: S2

## 症状

模拟器里设置界面文字是**纯白**、字体名是「ＭＳ ゴシック」、消息速度/音量等键全是 0；真机偏暗、
字体是用户配的 Amayui CN、各键有真值。dump 出来的配置路径是
`%APPDATA%\Eushully\天結いキャッスルマイスター\SYS4REG.INI`（漫游），而真机那份在
`%LOCALAPPDATA%\...`（本地）。

## 判据（spec 一直是对的，是实现偏离）

- `data/spec/chapters/06-window.md:341`：配置根 = `set:UseAppDataFolder` **恰为 1** ⇒ 平台「用户**本地**
  应用数据目录」（**不是漫游**）；其它值 ⇒ 空串、路径相对安装目录。
- `data/spec/chapters/65-save.md:25`：存档目录的根同一条口径。
- 实测两份文件都在：本地那份 960 B / `UseAntiFont=1` / `Font=Amayui CN`；漫游那份 903 B / 全 0
  （是我们自己的退时保存写出来的**影子文件**，引擎从不读写它）。

⇒ 缺口不在 spec，在 `apps/emulator-cxx/src/boot.cpp`：它读的是 `APPDATA`（漫游），并且用
`!= 0` 而不是 spec 的「恰为 1」。

## 后果

1. 玩家层**整份没被读到**：AA 开关（⇒ 文字比真机亮一档）、字面名、消息速度、音量…全部落到发行默认表/0。
2. 退时保存写的是漫游那条**引擎不看的路径** ⇒ 看起来"配置能存"，实际存到了另一个世界。
3. 修路径之后如果不加闸，退时保存就会去覆盖**真机那份**（外部只读数据）—— 同一处必须一起处理。

## 修法与守卫

- `core::player_config_root()`（纯函数，`core/config.h`）：本地应用数据 → XDG 数据目录 → `~/.local/share`
  → 安装目录；漫游候选**只出现在诊断打印里**，选择逻辑不读它。
- `core::should_save_player_config()`（纯函数）：真实玩家配置（落在解析出来的根里面）**默认不写**；
  要写得显式指路（`--config <副本>` 或 `--config-save`），`--no-config-save` 强制不写。
- CTest `emulator-core-config-root`（纯档）：两个候选都给时必须选本地那个、只剩漫游候选时不许回退、
  保存闸六条分支。把根换回 `%APPDATA%` 或去掉闸 ⇒ 这条红。
- `apps/emulator-cxx/README.md` 的「玩家配置」一节记了宿主闸与两个开关。

## 复现（历史形态）

把 `player_config_root` 的本地候选换成 `roaming_app_data` 后跑
`ctest -R emulator-core-config-root`：`两个候选都在时必须选**本地**应用数据目录` 当场红。
