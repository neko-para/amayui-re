# S2c · Engine 根锚定（G13 全局载体 + 从根正向传播）

口径：`T0`（= IDA 里的 `Command`）**不是任何函数的参数**，只能从数据段进来 ——
所以"类判定靠调用链"这条在**根**上原本没有起点，只能从 op handler 倒着爬。
本单把起点补上，并让传播从根**正向**走。

## 证据（锚只有 EA）

| 环节 | EA | 逐字指令 |
|---|---|---|
| 分配 | 0x4baa11 | `push 0AABC8h`（Size = 699336） |
| 分配调用 | 0x4baa16 | `call ??2@YAPAXI@Z`（operator new） |
| 构造 | 0x4baa2e | `mov ecx, eax` + `call sub_415640` |
| **存进全局** | 0x4baa3a | `mov ds:dword_55E1BC, eax` |
| 所属函数 | 0x4ba890 | `_WinMain@16`（窗口类 `ARCGameEngine`，WndProc = sub_4B92F0） |
| 销毁侧 | 0x4bb54a | `mov ds:dword_55E1BC, ebx` |

交叉检验：已知成员 `T0+0xaab20`/`+0xaab24`/`+0xaa514`/`+0x69330` 全部落在 0xAABC8 内；
构造器末尾 `lea ecx,[esi+0AAB74h]` + `push 3` / `push 1Ch`（eh vector ctor iterator）正好收在 0xAABC8。

## 判据

1. 载体新增 `kind:"global"`（`{sym, type, witness}`）；`witness` 必须**至少一条是写该符号的 store**（G13）。
2. 传播新增 `global(sym) ⇒ 该符号声明的类型`；没声明的全局**不传播**；被调方**必须真的收 this**（排除 `__cdecl`）。
3. 传播遵守 **"声明 > 推断"**：被调方有载体时，推断出的另一类只记 note（"调用方类在该偏移上相容"），不记冲突。
4. `sub_415640`（890 个形状站点的构造器）**尚未**声明载体 —— 它的成员表是 S2d 的活。
5. 违规即红：缺 witness / witness 是读 / witness EA 在语料里不存在 / 类型未声明 / 同一符号两种类型。

## 反例（必须记住）

**同偏移不同类不是冲突**：`sub_4034C0` / `sub_4034D0` / `sub_4034E0` 是 `this->+0x4` 的**转发器**
（`0x4034c3 mov ecx,[ecx+4]` + `jmp sub_497620`；`0x4034d3` + `jmp sub_4976A0` 格式化；
`0x4034e3 mov ecx,[ecx+4]; mov eax,[ecx]; mov eax,[eax+8]; jmp eax` = **虚调用**），
被 4 个类当 this 调用（`T0` 与内嵌子对象 `T_1ee8`/`T_4ed10`/`T_a609c`）—— 它们的 `+4` 上是同一个东西。
⇒ 已声明成**适配器类型** `T_ptr4 = { +0x4 : ptr→未知 }`（位置确定、目标未知，⛔ 不许编目标），
传播因此遵守 **"声明 > 推断"**：被调方已有载体时，推断出的另一类只记 note，⛔ 不记冲突。
