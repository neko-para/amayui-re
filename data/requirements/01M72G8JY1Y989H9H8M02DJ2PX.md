## 一句话
`TITLE→OPTION→左侧「ADV设定」` 与 `TITLE→GameStart` 两条路径都在 `0x4586AA` 抛 `std::out_of_range("invalid vector<T> subscript")`，无人接 ⇒ `_CxxThrowException` 返回后走到 CRT 的 `int3`（摘要 `stop: unimplemented @ eip=004E6E3F`、`detail: 软件中断（M1 不建模中断表）`）。根因：引擎的**字体名表**只有一条 `Amayui CN` —— 我们只枚举了宿主族名，而引擎按它自己配置里的字面名（`ＭＳ ゴシック` / `ＭＳ 明朝` / `AGE Extend` / `IPA P…`）查表 ⇒ 查不到 ⇒ `-1` 当下标。

## 处置（已落地，2026-11-10）
`src/shims/gdi32_font.cpp` 的 `shimEnumFontFamiliesExA` 改成**按固定名单逐条回调**（16 条：宿主 `Amayui CN` + `ＭＳ ゴシック`(EA 0x52686C) / `ＭＳ 明朝` / `AGE Extend`(0x5268F9) / `IPA Pゴシック`(0x5268CC) / `IPA P明朝`(0x5268C0) + `.data:0x52985C` 那 10 条已知族名），字形仍一律来自宿主 Amayui CN（名字只是标签）。`@` 开头的竖排族名不报（`Proc` 跳过下标 0 的 `@`，`sub_428990` 查表时剥 `@`）。多回调走 `guest_call.h` 的"续延里再 `start()` 返回 false"（同 DDraw `EnumDisplayModes`）。

★ **回调极性 = 非 0 继续 / 0 停止**（MSDN `EnumFontFamExProc`；引擎 `Proc` EA 0x45EAC0 所有路径 `mov eax,1`）。之前 shim 注释写的"非 0 = 停止"是**错的**，照它写会让枚举在第 1 条被自己掐断、崩溃照旧（实测）。
