# S2ac · 负的二级偏移 = 折叠层 artifact（判不了，不是"缺成员"）—— 已落

## 现象

`--by-type` 里长期挂着一条 `T_5d8bc 1 个偏移 / 1 次访问 热点 0x-4`，claims 正文是
`⚪ 0x40eaa2 二级偏移 0x-4 不是 T_5d8bc 的成员` —— **负偏移**根本不是"某个类型缺一格"。

## 现场（EA 可复核）

```
0x40EA97  lea  ecx, [eax-4]        ← 取址算术带 −4
0x40EA9A  push offset sub_40B3F0   ← 一个 __thiscall 回调
0x40EA9F  mov  [ebp+arg_0], ecx
0x40EAA2  mov  ecx, [ecx]          ← 以 eax-4 为基址读第一跳
```

`pointeeOff = -4` 说明**路径的基准不是我们以为的那个对象**（可能是"结点前缀/带 header 的容器"这类
`base - 4` 惯用法），属**判不了**。

## 处置

`shape-claims.mjs` 的 G5' 循环里加一档：`pointeeOff < 0` ⇒ 计入 `pointeeBad`（守恒② 的“拒绝/未声明”档）
+ 一条 note，**不再产生负偏移的残差条目**：

```
G5' c04 @0x40eaa2: 二级偏移为负（0x-4）⇒ 取址算术把基准折叠错了，**判不了**（⛔ 不是"缺成员"）
```

效果：`--by-type` 里 `T_5d8bc` 整项消失；守恒① 不变（`8411 = 8400 + 11`），守恒② 各项不变（`1` 条“拒绝/未声明”）。

## 还没做的（下一步）

**上游闸门**：现在只在 claims 兜底（下游拦）。真正的修法在 `shape-access.mjs` 的折叠处。

### 合成复现（已做，能稳定重现）

`.tmp/shape/probe-negative-pointee.mjs` 用五行合成 `.lst` 就重现了：

```
00402002  mov  eax,[esi+100h]    ⇒ abs=0x100  pointeePath=[]      pointeeOff=null
00402008  lea  ecx,[eax-4]       ⇒ access=a   pointeePath=[0x100] pointeeOff=-4
0040200B  mov  ecx,[ecx]         ⇒ access=r   pointeePath=[0x100] pointeeOff=-4
```

⇒ 成因定位到 **`lea reg,[<一跳基址>-K]`**：折叠保留了 pointee 路径，却把负位移原样写进 `pointeeOff`。

### 两案（都没落：都需要先有 **access 层** 的守卫用例才算"会红"）

1. **置 null**：`shape-access` 里 `pointeeOff < 0` 时写 `null` + `problems.push('neg-off')` ⇒ claims 天然进"判不了"档。
2. **打标记**：保留 `pointeeOff`，另给 `pointeeOffNeg: true`，claims 用它单列（信息更多，但要改两处判据）。

★ 采纳 1 的前提：`tools/test/` 里要有一条能直接跑 `analyzeLines` 的用例（现在只有 claims 层的合成用例，
**access 层没有独立测试文件**）—— 这本身是一小步基建，先建它再改代码。
