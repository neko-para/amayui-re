## 一句话
`--raster gpu` 臂**整层丢 Live2D 角色**（FF 纹理批零片元），而 `gpu=124/124`、`fallback=0`、`--gpu-strict` 绿 ⇒ 静默的产品路径缺口（S1）。

## 根因（已定案）
`d3d9::clear(ZBUFFER)` 走 `m->gpuRaster()->rasterRequestDepthClear()`，而转发壳 **`SdlWindow`（present_sdl）没声明/转发这个虚函数**
⇒ 调到基类空实现（`[gpu-depth] arm=clear` 整跑 **0 行**）。D32 只在 `rasterPrepare` 建 target 时清过一次；
每帧末尾一张**全屏 `z=0.0`、深度写开着**的 12 顶点 quad 把整屏深度写成 0 ⇒ 下一帧 `z=0.5` 的 FF 批（`LESSEQUAL`）全 `0.5<=0` 判假 ⇒ 整层消失。
那张 `z=0` quad 与关深度的 sprite 照落 ⇒ 画面是"一层平面暗幕"，账本全绿。★ **fade 能落不能证明深度正确**（它 `z=0`，LESSEQUAL 永远过）。

## 交付
- `present_sdl.h` 补 `rasterRequestDepthClear() override`；`present_sdl.cpp` 加转发，并把 12 处直接读 `impl_->gpu_raster` 收到唯一取用点 `impl_->raster()`（供夹具缝）。
  **转发面审计**：`GpuRaster` 16 个虚函数，修前**恰好漏这一个**；修后 **16/16 全 override**。
- 守卫 `tests/gpu_batch.cpp#gpu-batch/depth-clear-forwarded`（pure，**穿过壳**：注入 Mock + `m.setGpuRaster(&window)`，直连后端抓不到）：
  `Clear(TARGET|ZBUFFER)` ⇒ 后端计数 1；`Clear(TARGET)` ⇒ 仍 1（反向）；另逐条断言其余有副作用的转发。268 checks。
- 变异：转发行改 `(void)r;` ⇒ `--match depth-clear` **1/1 红**。
- 端到端（无 env）：角色区 `TH10 0.644% / TH6 3.954% / row_hf 0.8653`（修前 `0/0/0.1424`）；与 CPU 臂 **15.407% / mean|Δch| 0.714**（修前 95.794% / 6.606）；
  与 `LIFT_GPU_ZTEST=always` 臂 **BMP 逐字节相同** ⇒ 语义 = 每帧清一次深度。`[gpu-depth] arm=clear` **0 行 → 2 帧 3 行**。

## 已否掉的（**负结果，别再查**）
纹理副本陈旧 · guest 覆盖镜像 · 视口二次映射 · scissor · 没进 pass · 深度**清值**（guest z 恒 1.0）· mip 采样（`bin3` 无 mip 代码且帧与 `bin6` 逐字节同）·
`LIFT_NO_MIP`（只被 CPU 光栅器消费）· FF 管线本身（无纹理 FF 批逐点吻合 CPU）· 顶点链（布局/shader 逐字段对齐、无共用 staging）。
★ 其中 A13 用字节串证明 `bin3` 无 mip 代码 ⇒ 失败在 level 0 就已存在；A14 的 1×1 texel 对打证明 level 0 内容 **hash 与 guest 相同** ⇒ 纹理无罪。
