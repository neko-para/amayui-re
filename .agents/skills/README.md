# .agents/skills/ — 技能落点（**发现路径固定，不可改名 / 移位**）

> ★ 这个目录**必须存在**、且**必须叫这个名字**：DSH 按 `.agents/skills/<名字>/SKILL.md` 的固定路径发现技能。
> 这不是风格问题，是**硬要求** —— 不要为了迎合别的注册方式去改名 / 移位 / 加一层中间目录。

## 1. 本轮状态

**只有这份说明性 README，没有任何技能。**

旧仓的 `.agents/skills/`（实测 **8** 个技能）**不迁移**：用户口径是"几乎所有技能与工具都需要重新适配"，
因此全部按 `rebuild` 处理 —— 只留"重写时读得到旧实现"的指针
（`corpus/assets.json` 的 `agent/skills`）。

## 2. 怎么写（M6 重建时）

```text
.agents/skills/<技能名>/SKILL.md    ← 必须在这里；DSH 直接发现，无需注册
```

* 技能内容**从零重写**，不抄旧仓；
* 技能若需要脚本，脚本随技能目录走，但**不要**再让技能承担跨域关注点
  （旧仓症状：10 个跨域守卫寄生在模拟器的 `test/` 下）；
* 技能要消费知识时，只能消费**过了准入门**的台账条目（见 `AGENTS.md` §6）。

## 3. 与插件的区别

| | 落点 | 注册 |
|---|---|---|
| 技能 | **固定** `.agents/skills/` | 无需注册（路径即发现） |
| DSH 插件 | 位置自由（本仓源码落点 `plugins/`） | 软链接注册，环境级动作、要重装 |

详见 `docs/04-agent/README.md`。
