# Amayui Shape（对象 shape：**模型只写判断，工具给坐标与判定**）

## 0. 四条最常踩的

1. **类型是中心数据，不许写进族文件**。类型真源**只有一处**：`data/shape/types.json`（少数定义、多数载体）。
   族文件（`data/shape/<族>-handlers.json`）**只放 `carriers`**，一律 `typesFrom: "types.json"`。
   ⛔ 把 `types` 写进某个族文件，会让**别的族文件**被迫引用那一个族（"数值族的文件成了全仓的类型真源"）——
   组织上说不通，改一处类型还要动无关文件。（`typesFrom` 的**合并**语义仍保留：同名类型按成员增量合并、同 `off` 本地优先。）
2. **字段不是载体**。`obj0+0x5D894` 处的成员是**容器类型**（`T0`）的成员，写在 `types.json` 的成员表里；
   `carriers` 只放**机器槽**（`arg` / `local` / `global`）。把同一个成员同时写成"field 载体"和"类型成员"
   = 同一件事三份写法 ⇒ 必漂（实测：改一处类型，另一处不动）。
3. **`baseHop` 不是对象层级**。形状层的 `baseHop` 是**基址值的来路**（= 指针**路径**的长度）；
   **对象层级 = 路径长度 + 1**（判据函数 `objectLevel()`，在 `lib/shape-claims.mjs`）。
   差这一层，**层级 3** 整类会漏出"超出解析深度"桶 —— 而上限冻结在层级 2 时，那一类**正是最该被发现的东西**。
   ★ 层级是**逐跳走出来的**，但**路径只管一跳**：`lea [<二级对象>+k]` 之后解引用要靠 `pointeePath` 救回来
   （早先只带"最后一跳的偏移"，它报成层级 1、从所有桶里掉出去）；**跨两级以上不判**（进专门一档，带 EA + 路径），
   要判就写一条**局部类型载体**（见下）。实测代价：一跳 10 条声明覆盖 125 处；两跳 2 条只覆盖 8 处
   却要带来"链遍历 + 下钻政策"整套复杂度。
4. **`span` 不许自己写**。先跑 `regions`，再**逐字引用**它导出的段落（`from`/`to` 两个 EA 完全相同）。
   ⛔ **不许合并相邻段落**：那会把"被复用过的寄存器"缝成一个看起来干净的推进链。

## 1. 什么时候该动用它

* 要声明"**某个 `sub_XXXXXX` 的 `ecx` 装的是哪个类型的对象**"（载体）；
* 要声明"**某个类型由哪些偏移构成**"（成员表：偏移 + 宽度 / 元素类型 + count；洞不写）；
* 要声明"**某段 x~y 里 d 是循环迭代器 / 状态域**"（`roles` / `domains`）；
* 要回答"**这些声明跟汇编对不对得上**"（校验）；
* 要回答"**还有哪些访问没被解释**"（**残差 = 下一轮要做什么**）；
* 要**独立复核**某条结论的 witness EA（⛔ 不许信模型的转述，回语料重解）。

反过来：**它不是台账**。字段含义 / 函数用途 / 名字，仍然只能按 `AGENTS.md` §6 绑可再校验观察后登记。

## 2. 四步工作流（★ 顺序不可颠倒）

```bash
# ① 拿坐标（机械导出；模型只能**引用**，不能改）
pnpm tools shape regions sub_40ED40 edi   # 段落 / 类别 / 段首形态 / 是否被 call 打断
pnpm tools shape access  sub_42AEA0       # 逐 site 访问记录（EA 锚；含 pointee / level）
pnpm tools shape depth                    # 对象层级分布（用来现跑"上限冻结在层级 2"这个判决）
pnpm tools shape census                   # ★ 全表普查：每个**有 handler 的 opcode** 的偏移聚类 / 索引簇 / 未解析报数 / 各层级站点数
                                          #   （`--match <sym>` 收窄 · `--json` 全量）——**族边界的依据**来自这里
pnpm tools shape bodies                   # ★ handler 体骨架：记录槽写法 + 调用序列 ⇒ 按骨架分组（A 层唯一要判的"族边界"）
pnpm tools opcodes handlers               # opcode ↔ handler 符号（"桥"；⛔ 不写进产物）

# ② 写 claims（**只写判断**；JSON）——**类型与载体分两个文件**
#    类型真源：data/shape/types.json        （types；**唯一**一份）
#    族文件　：data/shape/<族>-handlers.json（**只放 carriers** + "typesFrom": "types.json"）
#    可选分节：roles · domains · escapes · identities

# ③ 校验（功能②）——**类型真源与每个族文件都要跑**
pnpm tools shape claims data/shape/types.json
pnpm tools shape claims data/shape/<族>-handlers.json
pnpm tools shape claims --sample          # 内置样本：改了校验器先跑它

# ④ 独立复核（功能②的另一半：不信模型，按 EA 回语料重解）
pnpm tools shape verify 0x42af25
```

★ **残差不是失败，是清单**：把残差逐条判断（缺一个成员？那是**另一个对象**？还是这个载体本就不该是这个类型？），
然后**增量**补到**类型真源**里（⛔ 不是补进族文件）。`typesFrom` 的合并语义是"同名类型按**成员**合并、同 `off` 本地优先"：

```jsonc
// 族文件：只放载体；类型一律引用中心真源
{ "schema": "amayui.claims/1", "typesFrom": "types.json",
  "carriers": [ { "id": "n01", "kind": "arg", "fn": "sub_42C5E0", "reg": "ecx", "type": "T0*" } ] }
```

★ 报告里**解释不了的桶**（`ds:` 符号 / 未解析基址 / **二级对象内嵌派生**）是"形状层表达不了"，
**不是**"已通过"：它们由**守恒③**兜着，不会被静默丢掉。

## 3. 判据（红了意味着什么）

* **四档话**：`holds` / `refuted`（必带 **witness EA + 哪条义务**）/ `unverifiable`（给不出判定）/
  **`unfalsifiable`**（没有任何用法约束它 ⇒ **不算通过**；空话声明必须单独报出来 —— 已实现为 **G7**：
  成员声明 `kind:"ptr"` 却在本模型载体集里**零解引用** ⇒ 单列；**不判红**，因为类型是共享的、别的族可能才用它）。
* **三条守恒**（对不上就是脚本错，不是"差不多"）：
  ① `obj0 访问 = 解释 + 残差`；② `二级对象 = 目标类型解释 + 不透明 + 拒绝/未声明`；
  ③ **`站点 = obj0 相对 + 位移不可用 + 二级对象 + 二级对象内嵌派生 + ds: 符号 + 未解析基址`**
  （没有③时，后四类会**从访问总数里静默消失**：数字变小，不报错）；
  ④ **`解释 = 观测档 + 视图推测档`**（没有④，就审不出"哪条结论是模型猜的"）。
* **"猜"要写成声明，不要写成观测**：同一批字节的**另一套原点**（先例：`0x5d894 + 0x78·(索引−1)` ≡
  `0x5d81c + 0x78·索引`）写成数组成员的 `views:[{elementDelta:-1}]` —— 那是**模型的推测**：
  判定器只做**算术自洽**（`成员 off + 步长·delta == 被解释的位移`）与**可证伪性**（零观察 / 多余 ⇒ 单列），
  报告里标 `🧩…**推断**`。⛔ 不声明就**如实进残差**，不许静默圆成"元素 0"。
* **二级对象/多跳：两条路，口径是"来源可表达吗"**
  * **路径**（`{off, kind:"ptr", type:"T…"}`）：从 `obj0` 的成员读出来的指针 —— **推导**，零声明，
    **只管一跳**（一次成员查找）；跨两级以上**不判**（进"跨两级以上（未判）"档，带 EA + 路径）；
  * **局部类型载体**（`{kind:"local", fn, reg, span:[from,to], type:"T*"}`）：来源**不可表达**时
    （参数 / 调用返回值 / 数据段 / 跨层级）—— **断言**。G10 三条硬要求：`span` 必须逐字等于 `regions` 的
    **活窗口** `[from..liveTo]`（⛔ 不许自己写）· 活窗口里被 `call` 打断的 caller-saved 不许用 ·
    段落类别必须是 `load`/`ptr`/`other`。★ 实测它能**跨过下钻上限**（判掉了层级 3 的站点）。
    ⛔ 两条路对同一处并存 ⇒ G10 报 note（同一事实两套声明）。
* **"条数未观察"的数组**：`type` + `count: null` + `sweep:{stride,index}` —— 形态（步长 + 索引身份）
  说得出来、边界说不出来。⛔ 缺 `sweep` 会让窗口**无界** ⇒ 吞掉窗口外的偏移（**假解释**）。
* **判"未解析基址"前先分清三种**（踩过一次：把助手缺口当成"来源不可表达"，于是差点用假类型盖住）：
  ① **助手丢值**（`noreturn` 之后连了 fall-through / 对象根经栈槽往返）⇒ **修助手**，不是加声明；
  ② **SEH catch 块**（唯一引用在 `.data` 的 SEH 表里 ⇒ 静态无入边）⇒ 用 `{kind:"local", …, type:"T0*"}`
     表达"这个寄存器在这个块里就是 obj0"，⛔ **不许编匿名类型**（`T_429460_esi(0x8|0xa609c)` 就是 T0 的成员集 = 假类型）；
  ③ **真跨函数 / 调用返回值 / 数据段符号** ⇒ 才是 local 载体或"形状层表达不了"。
* **两道守卫**：**词汇**（`opcode`/`argc`/`operand`/`lengthWord`… ⇒ 那是 B 层 `data/ledger/` 的事）·
  **冗余**（`mn`/`defines`/`callee`/`argImm`/`const`… ⇒ 能从 EA 读出，写进产物就是第二份真源）。
  ★ 两道守卫跑在 **`typesFrom` 解析之后**的模型上 ⇒ 被引用的类型文件同样受守。
* **义务**：G1 自洽（不重叠 / 不越 `size`）· G2 覆盖（**两级**：容器成员 + **数组成员的元素内成员**）·
  G3 步长（数组形态：观测步长 == `size(元素类型)`）· G4 数组边界（末尾地址必须在语料里被引用）·
  G5/G5' **下钻**（宿主必须声明 `kind:"ptr"` + 目标类型 ⇒ 用目标类型的成员表再跑一遍）· G6 未观察成员 ·
  **G7 可证伪性**（见上）· **G8 成员声明自洽**（见下）。
* ★ **成员的三种合法形态**：**内联值**（给 `width`）· **数组**（给 `type` + `count`，元素类型要给 `size`）·
  **条数未观察的数组**（`type` + `count: null` + `sweep`）。缺一半 ⇒ **G8 红** ——
  跨度算不出来时，判定器会把它**静默当成 1 字节槽**（实测：帧数组的访问变成"不落在任何已声明成员上"的残差，
  而旧版一条红都没有）。★ 注意 `count` **省略**与 `count: null` 是两件事：前者是"声明不完整"（红），
  后者是"明确声明条数未观察"（要配 `sweep`）。
* ★ **`type` 在成员上有两个互不相干的意思**：`kind:"ptr"` 时它是**被指向的类型**（不该配 `count`）；
  否则它是**数组元素类型**（必须配 `count`——写 `null` 就得配 `sweep`）。⇒ 声明 `kind:"ptr"` 的成员要写 `width` + 可选 `type`。
* ★ **`views` 是推测**（G9）：算术由工具校验、可证伪性由工具盯（零观察 / 多余 ⇒ 单列"空话声明"），
  **语义不由本层背书**；裸位移与视图窗口重叠时**规则定**（选标量），选不出 ⇒ 单列 `ambiguous`。
* ★ **不透明 ≠ 通过**：声明了 `kind:"ptr"` 但 `type: null` ⇒ 进**不透明桶**单列（带 EA），那是"不可检查"。
* ★ **层级 ≥3 单列**（逐处打 EA）：上限冻结在层级 2，但 ⛔ **不许静默丢**。
* ★ **`complete: true` 是强声明**：该类型多一处没解释的访问就红。不确定就别写，让残差说话。

## 4. 六条硬口径

1. **锚只有 EA**；键 / 引用只许用 **EA · 地址表达式（`*(obj0+0x5d880)`）· 位次名（`obj0`）**；
   语义名只许放进 `label`（可选，**不参与判定**，⛔ 不许当键）。
2. **能从 EA + 语料机械读出的东西一律不进产物**：助记符 / 调用目标 / 立即数 / shape / 行号 / 长度字。
3. **类型是中心数据**（少数定义、多数载体）：唯一真源 = `data/shape/types.json`，族文件一律 `typesFrom` 引用，
   ⛔ **不许抄一份、也不许反过来把类型塞进族文件**。
4. **不读 `apps/emulator`**（同层产物，不是依据）；真源只有 `corpus/disasm/files/*.{lst,c}`。
   `.c` 只用来读**调用约定**与结构第二意见；它一处地址都没有，**不许当锚**。
5. **两个实现不许合并**：助手（`lib/shape-access.mjs`，整个函数前向）与复核器
   （`lib/shape-verify.mjs`，从 EA 向后的局部切片 + 闭集合惯用法表）**不共用解析 / 折叠代码**；
   表外形态一律 `unverifiable`，**不许猜**。
6. **名字 / 语义 / opcode 语义 → 台账**（`AGENTS.md` §6）：本层产物里 ⛔ 不许出现 `opcode` / `argc` /
   操作数序号 / 长度字 —— 词汇守卫会红。

## 5. 常踩的坑（都有实测出处）

| 坑 | 症状 | 处置 |
|---|---|---|
| 把 `types` 写进族文件 | 别的族文件被迫引用那一个族 ⇒ 类型有了第二份写法 | 类型进 `data/shape/types.json`；族文件只放载体 |
| 只守族文件、不守类型表 | `typesFrom` 引用的文件里塞 `argc` / `mn` ⇒ **两道守卫一起静默失效**（实测退出码仍 0） | 已修：守卫跑在**解析后**的模型上；变异清单有对应条目 |
| 成员 `type` 缺 `count` | 跨度算不出 ⇒ 判定器**静默把它当 1 字节槽**，帧访问变残差却零红 | G8 红；元素类型缺 `size` 时**明说**"按 1 字节处理" |
| 守恒只有单边记账 | `ds:` 符号 / 未解析基址 / 二级对象内嵌派生**从总数里消失**（数字变小） | **守恒③**按基址分桶；`--match shape` 有对应变异 |
| 索引没解出来的访问当偏移观察 | `mov [esi+edx*4],eax`（`edx` 未知）报成 `abs=0x0` ⇒ **假残差**，甚至"正好命中成员"⇒ **假解释** | `offsetUnusable()` 剔出（普查与判定共用一份）；变异钉住 |
| 把"推测"写成观测 | "这是同一个数组、索引差 k"直接当成事实 ⇒ **假解释**（且看不出哪条是猜的） | 写 `views:[{elementDelta:k}]`：工具只判算术自洽 + 可证伪性，报告标 `🧩…**推断**`；守恒④ 分档 |
| `count:null` 不配 `sweep` | 窗口**无界** ⇒ `0x5ee04` 一路"解释"到 `0xa609c`（假解释） | `count:null` 必须给 `sweep:{stride,index}`；窗口 + 索引身份双重约束（变异钉住） |
| `kind:"ptr"` 声明了却零解引用 | 空话声明**静默绿**（没有任何用法约束它） | **G7** 单列（⛔ 不算通过，但不判红） |
| 把字段写成载体 | 同一成员三份写法 ⇒ 改一处另一处不动 | 字段进 `types` 的成员表；载体只放机器槽 |
| `baseHop` 当层级 | **层级 3** 整类从"超出解析深度"里漏掉（实测 812 处） | 用 `objectLevel()`（= `baseHop`+1） |
| 自己写 / 合并 `span` | 复用过的寄存器被缝成"干净推进链" | 逐字引用 `regions` 导出的段落 |
| 数组成员没给元素 `size` | 跨度算不出 ⇒ G1 重叠、G4 边界**判不了** | 要么给 `size`，要么接受工具**明说**"判不了" |
| 用字面量出现次数判"未观察" | 折叠形态（`0xC79×0x78` 算出来的 `0x5D8B8`）被误报未观察 | 传**形状层观察集**（`--claims` 会自动算） |
| 为了变绿编成员 / 改判断 | 最严重的错误（假绿） | 先分清"我错 / 工具错"，残差**如实**报出来 |
| 用 `stdio:'pipe'` 抓子进程输出 | 受限沙箱 `spawn EPERM` ⇒ 被读成"校验器红" | 用**文件描述符重定向**（`AGENTS.md` §5 ①） |
| 带修饰符的调用约定 | `void __thiscall __noreturn sub_x(int this)` 曾让对象根抓不到 ⇒ "0 访问"却通过 | 已修；且**查不到对象根一律判红**，不许假绿 |
| 守恒单边记账 | 二级对象残差进分子不入分母 ⇒ 恒等式必然差数 | ①②分开记 |
| 声明 `ptr` 却不给目标类型 | 该访问被当"已声明"静默通过 | **不透明桶**单列（⛔ 不算通过） |
